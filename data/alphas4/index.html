本文为分析师预期与业绩发布（Analyst & Earnings）专题篇（日频量价见 alpha11，日内微结构见 alpha28，基本面三表见 alphas2，新闻与社媒情绪见 alpha29）。全表算子严格对齐 WorldQuant FASTEXPR 规范，仅使用通用卖方预期与财报字段概念，脱离具体数据库编号即可自解释。

一、Analyst & Earnings 衍生数据三阶谱系（0→1→2 阶 + WorldQuant FASTEXPR 对齐）

与基本面类似，分析师数据核心围绕“一致预期中枢、分析师分歧、上调/下调修订节奏、业绩实际超预期差（PEAD）”展开，按结构分为三阶：0 阶为原生卖方预测、评级、实际业绩与财报日历字段；1 阶为单步标准化、前瞻估值、修订广度比、实际 vs 预期差与单层 ts_* / vec_* 脉冲；2 阶为跨维度复合（如财报倒计时加权、风险回归残差、行业逆风突围与基本面联合门控）。

图例说明：在一至二阶衍生指标中，绿色加粗条目表示已在本地平台实测记录中检索到达标信号（非 SUPER，fitness >= 1.0 且 sharpe >= 1.2；除 CHN 地区外，fitness <= -1.0 且 sharpe <= -1.2 的反向可取负信号亦计为达标）；红色加粗条目表示库中已有实测记录但未达上述门槛；默认颜色为尚未在库中检索到独立测试记录的理论或扩展方向。

0 阶数据（原生预期、修订计数、业绩与日历） 一阶数据（vec_* 归约、预期估值、修订比与单层 ts_*） 二阶数据（财报窗加权、行业背离、残差与多因子协同）
一致预期水平与分布
• 盈利/营收预期均值与中位数：eps_est_mean、eps_est_median、sales_est_mean、roa_est、ev_ebitda_est、div_yield_est_12m（未来 12 个月或财年一致预测）
• 预测分歧与覆盖度：eps_est_std（各券商预测标准差）、target_price_std（目标价分歧度）、num_est（覆盖分析师家数）

修正计数与评级目标价
• 修正家数：est_up_4wk、est_dn_4wk（近 4 周上调/下调盈利预测的券商家数）；cluster_est_up、total_est_up（密集爆发窗口与常规对比窗口的上调家数）
• 评级与目标价：rec_score（一致买入/卖出评级打分）、target_price（一致目标价）

实际业绩与财报日历
• 实际 vs 预测对比：actual_eps（实际公布每股收益）、prior_est_eps（公布前一致预期 EPS）
• 财报事件冲击与倒计时：ern_move_1d（最近一次财报公布日股价涨跌幅矢量）、ern_next_days（距下一次财报公告的交易日天数）、ern_pre_days（距上一次财报公告已过去天数）
• 行情参照：close、cap、industry / subindustry		 前瞻估值与预期中枢
• 前瞻盈利 / ROA / 股息预期：eps_est_mean / close（前瞻盈利收益率）、ts_scale(roa_est / cap, 66)、div_yield_est_12m（衡量市场隐含前瞻回报与高股息预期）
• 分析师覆盖度特征 (num_est)：group_rank(ts_mean(ts_backfill(vec_max(num_est), 22), 5), country)（识别机构聚光灯效应与低覆盖冷门股价值重估区间）

修正广度与聚集爆发脉冲
• 净修正广度比 (rev_breadth)：up = vec_avg(est_up_4wk); dn = vec_avg(est_dn_4wk); (up - dn) / max(up + dn, 1)（上调净占比，在 \([-1, 1]\) 间直接刻画卖方一致情绪转向，抗单家极端预测干扰）
• 密集上调聚集脉冲 (cluster_rev)：ts_backfill(vec_avg(cluster_est_up) - vec_avg(total_est_up), 22)（捕捉短窗口内多家券商集体扎堆上调的密集建仓前兆）
• 推荐评级偏离脉冲 (rec_pulse)：-ts_av_diff(ts_backfill(vec_avg(rec_score), 63), 44)（评级一致分数相对过去两月均值的边际偏离与均值回归）

分歧度、分布偏度与目标价空间
• 目标价隐含涨幅 (pt_upside)：target_price / close - 1 或 ts_delta(target_price / close, 22)（因分析师普遍乐观偏见，绝对上行空间意义较弱，应取自身变化趋势）
• 目标价分歧度 (pt_dispersion)：ts_zscore(ts_backfill(target_price_std, 120), 120)（机构对未来定价的分歧程度变化）
• 预期偏度 (mean_median_skew)：ts_backfill(eps_est_mean, 120) - ts_backfill(eps_est_median, 120)（均值相对中位数的偏离，探测少数极端乐观/悲观大行预测）

实际业绩增长与财报跳空（PEAD）
• 实际业绩同比增速与波动标准化：ts_delta(max(ts_backfill(vec_max(actual_eps), 120), 0), 240)；ts_delta(actual_eps, 240) / ts_std_dev(actual_eps, 240)（将实际 EPS 同比增量除以历史盈利波动率，即业绩增长信息比）
• 财报日跳跃与跨日平滑 (ern_move)：ts_rank(ts_backfill(vec_min(ern_move_1d), 22), 5)、ts_decay_linear(group_zscore(ts_delta(vec_avg(ern_move_1d), 5), subindustry), 10)（刻画财报公布当日跳空超预期后的漂移效应 PEAD）
• 财报超预期残差 (surprise)：-regression_neut(ts_min_max_cps(ts_backfill(vec_min(actual_eps), 120), 5), ts_min_max_cps(ts_backfill(vec_avg(prior_est_eps), 120), 5))（实际 EPS 对公告前一致预期做横截面正交回归残差，剥离基准预期后提取纯粹惊喜）		 财报日历事件窗加权与门控
• 临近财报放大权重 (ern_window_boost)：weight = if_else(ern_next_days < 20, 2, 1); signal * weight（财报季前 20 个交易日内放大分析师评级/修订信号的仓位权重，抓住业绩前信息泄露与预期重定价窗口）
• 事件窗内量价协同门控：if_else((ern_next_days > 5) && (ern_next_days < 20), -ts_mean(returns, 5) * ts_rank(volume / adv20, 20), 0)（避开临近财报前 5 日赌博区，仅在财报前 5–20 日启用量价反转因子）
• 财报日后漂移过滤 (post_ern_gate)：trade_when(ern_pre_days < 30, surprise_signal, -1)（仅在财报公布后一个月内的 PEAD 黄金漂移期持仓，避免陈旧预期失真）

行业逆风突围与交叉配对
• 个股 vs 行业景气背离 (ind_divergence)：rev_breadth - group_mean(rev_breadth, cap, industry)（当全行业预测普遍下调时，逆势被分析师集聚上调的个股往往具备独立基本面 Alpha）
• 前瞻估值 × 量价/风险正交：ts_regression(ts_zscore(forward_pe, 252), risk_exposure, 252, rettype=0)（剥离市值与系统风险暴露后的纯估值预期因子）
• 覆盖度突变与冷门重估：ts_delta(vec_max(num_est), 120) 与反转/基本面质量复合（捕捉券商覆盖数“从 1–2 家突增至 5–6 家”的聚焦重估期）

二、分析师与业绩数据的四大机制与工程要点

  1. 核心 Alpha 来源不是“预测绝对准”，而是“黏性与预期差”
    • 卖方分析师出于维护上市公司关系和职业声誉考量，存在明显的从众心理与预测黏性（Herding & Conservatism）：当公司经营发生拐点时，很少一步调到位，而是分多次“小步慢走”逐次修正，这就造就了修订广度 (up - dn)/(up + dn) 极强的中短期动量延续性。
    • 同理，财报公布当天的实际收益与公告前一致预期之差（Earnings Surprise / 财报日股价跳跃），往往引发机构长达 1–2 个月的缓慢调仓（PEAD 财报后漂移）。
  2. 目标价普遍高估（乐观偏见）
    • 券商研报倾向于多发“买入”评级并给出显著高于市价的目标价。直接对 target_price / close 做截面排序意义有限，实战更看重目标价或评级的自身变化斜率（ts_av_diff、ts_delta）以及在行业内的相对位置变动。
  3. 稀疏矢量与事件日历清洗
    • 分析师修订、实际 EPS 与财报跳跃字段大量以 VECTOR 或仅在发布日非空的稀疏格式存在：必须先通过 vec_avg / vec_max / vec_min 归约为标量，再用 ts_backfill(..., 22~120) 延续有效窗口。
  4. “从冷清到关注”的覆盖度效应
    • 被几十家机构重度覆盖的大白马往往定价极充分；相反，覆盖家数从零星几家开始快速增加的腰部标的，容易在聚光灯效应下产生显著的价值重估。

三、在 analyze-dataset 中的实战应用（通道与配对规则）

  1. 通道③ 核心配对范式（economics_pairing_principles.md）
    • 预期 vs 实际（estimate ↔ actual → projection / exceed）：用实际公布业绩对公告前一致预期做回归残差（regression_neut / ts_regression），提取剥离市场先验预期后的纯粹惊喜（PEAD 逻辑）；
    • 时间修正差（current ↔ prior → spread）：比较近期窗口上调家数 vs 远期基准上调家数（cluster_up - total_up），或近 4 周上调 vs 下调净占比 (up - dn) / (up + dn)；
    • 行业聚合对照：计算个股修正广度相对所属 industry / subindustry 的超额修正，发掘“行业下行周期中的逆风上调标的”。
  2. 与基本面/事件日历协同（通道④）
    • 利用财报倒计时 ern_next_days 对传统低频或反转因子做动态分段加权或安全区隔离（避开财报发布前最后 5 天的无序波动，强化财报前 5–20 天与财报后 30 天内的 PEAD 信号）。

四、BRAIN 通用事件控制与防过拟合技巧（实战经验沉淀）

  1. 多维度联合中性化（笛卡尔分组 group_cartesian_product）
    • 同时消除行业与国家（或市值分桶）影响时，优先使用原生算子 group_cartesian_product(country, subindustry)（等价于编码 densify((group_B + 1) * 1000 + group_A)）再做 group_neutralize。
  2. 基于事件发生价的止盈止损保护
    • 记录某条件触发瞬间的锚定价格：close_at_event = trade_when(not(event), close, -1)；当后续股价偏离该锚定价超过阈值（如 10%）时强制截断平仓：if_else(abs(close - close_at_event) / close > 0.1, nan, signal)，避免在趋势反转后死扛到底。
  3. 调仓节奏与市场极端暴跌冷却（days_from_last_change）
    • 控制信号有效寿命：d = days_from_last_change(event); trade_when(d < period, signal, d > period)，在信号长期无变化时自动退场；
    • 极端危机熔断：计算同行业日内大跌股占比 ratio = group_sum(if_else(returns < -0.09, 1, 0), subindustry) / group_count(1, subindustry)，若板块系统性踩踏（ratio > 0.6），则通过 if_else(days_from_last_change(ratio < 0.6) < N, nan, signal) 暂停交易并强制冷却 N 日。
