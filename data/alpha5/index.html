本文为量化特征工程的“数据关系与跨维度配对总纲”：各单一领域的深度谱系见前序专题（日频量价 alpha11、日内微结构 alpha28、基本面 alphas2、分析师预期 alphas4、新闻与社媒 alpha29）；本文专门系统回答三个核心问题——拿到一类数据集往哪里切入（类型路由）、两列数据之间如何建立可解释的数学关系（五大关系键）、以及如何避免多算子组合退化。所有表达式均对齐 WorldQuant FASTEXPR 规范。

一、十类数据集类型与优先信号路由

拿到一个陌生数据集时，先判别其数据类型与原始/合成程度，再决定是“直接找双字段关系配对”，还是“必须先构造中间比率（流÷存量、跨量纲加权、比率化）”：

数据集类型 核心数据特征 优先信号方向与 FASTEXPR 切入点 工程注意事项
量价数据 (PV) 全市场高覆盖、日频连续或日内微结构切片 • 短期反转（-returns、(high + low) / 2 - close）
• 量价协同与流动性冲击（ts_corr(close, volume, 20)、abs(returns) / (close * volume)）
• 非对称波动率与高阶换手能量		 基础行情字段（close、cap、returns、volume）既可独立构造因子，更常作为其它内容数据集的估值/锚定参照系
基本面数据 (Fundamental) 低频季报/年报、NaN 空窗多、跨行业口径差异大 • 若只有分列科目，须先构造盈利质量/估值/杠杆中间字段（ebit / assets、eps / close、free_cashflow / enterprise_value、liabilities / assets）
• 再做 ts_backfill(..., 120) + 自身历史或行业内比较		 禁止未填充直接 rank；注意 PIT 发布时滞、季节性同比对齐及分母归零去极值
分析师预期 (Analyst / Earnings) 多为 VECTOR、更新稀疏、存在乐观偏见 • 修订广度净占比 (up - dn) / max(up + dn, 1)
• 预期与实际之差（PEAD 正交残差 regression_neut(actual, prior_est)）
• 评级脉冲与财报日历倒计时加权		 目标价绝对空间普遍高估，重在看自身边际斜率（ts_av_diff / ts_delta）而非绝对高低
新闻与社媒 (News / Social) 高频、信噪比极低、存在极端长尾与市值偏差，情绪衰减快（有效时效通常不超过 1 季度） • 禁止裸用计数：必须先做“流÷存量”密度化（ticks / open_vol、mentions / cap）或极性差 spread
• 最有效角色是 事件门控 trade_when 与低讨论度（social_buzz 低分位）过滤反转		 警惕自动行情快报噪音；高 buzz 常对应买盘透支反转；负面情绪传播远快于正面
期权数据 (Options) 含看涨/看跌期权隐含波动率（IV）与持仓量全链 • IV 微笑/偏斜配对：iv_call - iv_put
• 衍生品参与度（O/S Ratio）：open_interest / volume
• 多空情绪门控：trade_when(put_call_ratio < 1, iv_call - iv_put, -1)		 同一配对务必对齐相同剩余期限与执行价档位；搭配历史波动率分组效果更稳
风险因子 (Risk) 包含系统风险、特异风险、Beta 与多因子暴露 • 去风险底座：作被剥离对象（regression_neut(signal, risk_factor)）
• 风险收益替代与状态切换：risk_ret 替代原始 returns，或按系统风险/特异性波动分位作 bucket 分组或 trade_when		 单纯暴露风险因子往往是隐含 Beta 押注，重点在提纯特异 Alpha 或剥离风格偏斜
模型评分 (Model) 厂家已合成的打分/排名/预测收益序列 • 分数直接横截面排序或时序平滑（ts_decay_linear）
• 多模型预测一致性均值、分数变化率 ts_delta、以及与真实实现误差（MAE）加权折价		 换手常偏高（尤其日频机器学习预测），需默认配合衰减平滑或换手限速 ts_target_tvr_delta_limit
宏观数据 (Macro) 全市场横截面共享相同或按国家/行业分层的宏观时间序列 • 体制门控（Regime Gating）：trade_when(macro_regime > 0, stock_signal, -1)
• 个股暴露传导：ts_corr(returns, macro_shock, 60) 或 ts_regression(returns, macro_delta, 60, rettype=2)（提取个股对宏观的 Beta 暴露）		 全市场同值的纯宏观序列本身不能做横截面选股，必须绑定股票维度的反应弹性或用作门控开关
原始流/事件 (Insider / Institution) 高管买卖、13F 机构持仓、供应链关系分列出现 • 构造强度/密度中间字段：交易股数÷总股本（头寸变化强度）、持股数÷流通股（机构覆盖率）、金额×显著性（加权信心）
• 同量纲买卖方向（buy ↔ sell）直接做 spread 净额配对		 13F 披露存在季度滞后；内部人交易聚焦集群买入（Cluster Buy）与高管核心增减持
杂类与分组 (Other / Group) 静态/动态关系聚类、自定义标签或特征分箱 • 直接充当 group_neutralize / group_rank 的中性化维度
• 用任意连续特征构造动态分组：bucket(rank(feature), range='0,1,0.1') 或双分组交叉 group_cartesian_product(g1, g2)		 用连续矩阵自制动态 bucket 分桶时，常配合 densify 压缩空桶以保证算子稳定性

二、五大核心关系键（“拿谁比” vs “怎么比”）

配对工程的核心是把内容（哪两个字段比）与关系（用什么数学结构比）严格分离——同一对字段，换一种关系键，对应的就是截然不同的 Alpha 经济学机制：

关系键 核心经济学机制 典型配对范式（拿谁比） WorldQuant FASTEXPR 算子骨架 关键避坑点
spread
（价差/极性/时间/快照）		 同量纲对立面之间的净差额或归一化相对强弱 • 极性：pos ↔ neg、buy ↔ sell、call_iv ↔ put_iv、ask ↔ bid
• 时间：short_window ↔ long_window
• 快照：current ↔ delay		 • 归一化相对强弱（极推荐）：
(a - b) / (abs(a) + abs(b) + 1e-4)
• 链式组结构复合：
group_neutralize(group_scale((a - b) / (abs(a) + abs(b) + 1e-4), industry), country)		 必须同量纲；若量纲不一致或存在零点漂移，先 zscore / ts_rank 对齐后再做差；切忌对纯绝对差值不归一化就横截面混排
exceed
（偏离基线/预期突破）		 数据相对自身基线、同业基准、离散度或市场一致预期（分析师/模型预测）的异常偏离与惊喜突破 • 个体 vs 自身均值：data ↔ ts_mean(data, d)
• 个体 vs 行业加权均值：data ↔ group_mean(data, ts_mean(cap, 21), industry)
• 信息比（IR）：mean ↔ stddev
• 实际 vs 预期（分析师预测 / 模型预测）：actual data ↔ estimate data（如盈利/营收惊喜、现价 vs 模型公允值）		 • 时序均值偏离：ts_av_diff(data, d)、ts_zscore(data, d)
• 信息比突破：ts_mean(data, d) / (ts_std_dev(data, d) + 1e-6)
• 组内基线偏离：zscore(data - group_median(data, industry))
• 预期惊喜突破：(actual - estimate) / (abs(estimate) + 1e-4)、分歧度标准化 (actual - est_mean) / (est_std + 1e-4)		 严禁“组内去均值后再组内排名”：group_rank(group_neutralize(x, g), g) 因排序对平移不变会退化为等价于直接 group_rank(x, g)；预期比较前须 ts_backfill 对齐发布窗口并防零分母
projection
（投影/回归残差/去风险）		 从信号 y 中线性正交剥离因子 x（风险/均值基线/预期/行情），提取剥离共同趋势后的纯净突变残差 • 去风险暴露：data ↔ risk_factor
• 均值突变残差：data ↔ mean_data（如 group_mean(data, ts_mean(cap, 21), industry)）
• 预期差（PEAD）：actual ↔ estimate
• 价格锚定：data ↔ returns / close		 • 横截面正交：regression_neut(y, x)、vector_neut(y, x)
• 滚动时序回归提取突变残差（rettype=0）或传导斜率（rettype=2）：ts_regression(y, x, d, rettype=0)
• 组内正交：group_vector_neut(y, x, industry)		 regression_neut(y, x) 与 ts_regression 对两输入量纲与 NaN 极为敏感，回归前须统一 ts_backfill 并视情况 winsorize / rank
correlation
（时序协同/领先滞后）		 两个序列在同一时间窗内的联动方向或耦合紧密度本身即为体制信号 • 量价协同：close / vwap ↔ volume
• 跨源共振：returns ↔ news_sent、value ↔ momentum
• 领先滞后：x ↔ ts_delay(y, k)		 • 滚动相关系数：ts_corr(x, y, d)
• 滚动协方差：ts_covariance(x, y, d)
• 相关性门控：trade_when(ts_corr(x, y, d) > 0, signal, -1)		 单纯 ts_corr 在短窗口易受单日极端值支配；若用作门控条件，建议窗口 d >= 20
combine
（组合/交互/影响因子）		 两个机制互相强化（如“超跌 × 放量”）或“总量 × 结构权重” • 共振强化：reversal ↔ volume_ratio
• 影响因子拆解：total_data ↔ part_ratio		 • 排序/分位乘积：rank(a) * rank(b)、rank(a) + rank(b)
• 有符号幂加权：signed_power(rank(a), p) * b
• 先分层再乘权重：if_else(cond, a, 0) * b		 两分支经济学方向必须事先统一（同向放大小/反向对冲），避免盲目相乘产生正负号混沌（负负得正）

三、多算子协同语义骨架（超越简单双字段）

当单一算子或简单双字段比较不足以表达完整交易逻辑时，高阶组合应遵循明确的经济学语义骨架，而非盲目堆叠随机算子链：

  1. 时间状态类（趋势演化与抗跳变平滑）
    • 快慢平滑基线差：ts_mean(x, d1) - ts_mean(x, d2)（如 5 vs 21、12 vs 26 捕捉边际加速）；
    • 二阶加速度排名：rank(ts_delta(ts_delta(x, 5), 21))（从水平切换为一阶速度的变化率）；
    • 抗跳变稳健平滑：先用历史波动率截断异常尖刺，再做线性衰减 ts_decay_linear(..., d)，控制低信噪比数据的换手率。
  2. 同伴结构类（跨组基准对比）
    • 相对组内中位数基准的全局偏离：zscore(x - group_median(x, industry)) 或对历史分位状态 ts_quantile(x, d) 在组内求 group_zscore(..., industry)，既有同业基准含义，又不会触发平移退化。
  3. 残差增量类（连续暴露分桶剥离）
    • 非线性分桶中性化：相比假定线性关系的 regression_neut，使用 group_neutralize(signal, densify(bucket(rank(exposure), range='0,1,0.1'))) 能直接剥离市值、波动率、流动性等非线性 U 型或分段暴露。
  4. 事件体制切换类（Trigger 与 Signal 严格解耦）
    • 触发器 vs 信号分离：条件分支（trade_when(trigger, signal, exit) 或 if_else(regime_cond, group_rank(signal, subindustry), group_rank(signal, sector))）中，决定“何时交易/切哪个粒度”的体制变量应独立于产生排序方向的主信号，避免单字段自相矛盾。
  5. 分布整形与执行控制
    • 居中排名非线性强调：对 rank(x) - 0.5 施加 signed_power(..., p)（p > 1 放大多空头尾极值权重，p < 1 压平尾部去极端）；
    • 目标换手率限速：在最终层使用 ts_target_tvr_delta_limit(signal, adv20, lambda_min=0, lambda_max=1, target_tvr=0.1) 将高换手微观信号约束至可交易区间。

四、四大经典经济学定价模型配对（actual vs model）

利用已知经济学理论从多个基本面/市场要素构造理论公允值 model data，本质上是生成一组自带经济因果的 actual data ↔ model data 配对内容（“拿谁比”）；具体加工时，直接按第二节五大关系键的算子骨架（“怎么比”）套用即可（下表“配对示例”仅为常见参考写法，不限于单一关系或单一算子）：

经济学模型 核心假设与适用边界 actual data（现实观测） model data（理论构造） 常用关系键 FASTEXPR 配对示例（非唯一写法）
1. CAPM 资本资产定价 市场均衡下超额收益由系统性 Beta 驱动 个股实际收益 returns 理论预期收益 E(R) = rf + beta * (rm - rf)；其中市场代理 rm = group_mean(returns, ts_mean(cap, 21), market)（截面忽略 rf 时简化为市场基准） projection / exceed 如 projection：ts_regression(returns, rm, 252, rettype=0)；或按 exceed 做 zscore(returns - rm)
2. 戈登增长模型（Gordon） 假设股息以恒定增长率永续增长；仅适用于成熟稳健派息行业（公用事业/必选消费） 平滑股价 ts_mean(close, 21) 理论股价 P_model = D_next / (r - g) = dividend * (1 + g) / (r - g)；其中：
• D_next = dividend * (1 + g)
• r = rf + beta * (rm - rf)
• g = b * ROE = (1 - dividend / income) * (income / equity)		 spread / exceed / projection 如 spread：(P_model - ts_mean(close, 21)) / (abs(P_model) + abs(ts_mean(close, 21)) + 1e-4)（r - g 须防零或负值，如 max(r - g, 0.01)）；亦可改走 projection 做 regression_neut
3. PEG 增长调整估值 假设短期盈利增速可外推；适用于成长科技/消费，周期股高点需逆向校正 静态市盈率 PE = close / eps 预期盈利增长率 G = (eps_est_next - eps_cur) / (abs(eps_cur) + 1e-4)（预期下年盈利增速） exceed / projection 如 exceed 比值：-(close / eps) / (100 * G)；或按 projection：regression_neut(rank(close / eps), rank(G))（均须过滤 eps <= 0 或 G <= 0）
4. 杜邦分析（DuPont） 将净资产收益率拆解为盈利能力、运营效率与财务杠杆乘积 利润率 ProfitMargin = income / sales 杜邦分解 ROE = (income / sales) * (sales / assets) * (assets / equity) combine / projection 如 combine（影响因子拆解）：rank(income / sales) * rank(sales / assets)；或按 projection：regression_neut(income / equity, assets / equity) 剥离高杠杆

五、多字段协作的底线原则

  1. 配对先问经济机制：任何跨字段关系都必须能用“五大关系键”或“四大经济学模型”讲清因果逻辑；讲不清经济机制的强凑回归或乘除，本质只是样本内过拟合。
  2. 先做意义中间字段，再谈关系加工：对于分列存储的原始流量/存量/基本面科目，必须先完成单位对齐、密度归一化或比率化构造中间字段，再进入单算子标准化或双字段配对。
  3. 参照系与独立分类权衡：当内容数据集缺少价格/市值/风险维度时，按角色从 PV/Risk 基础元素池引入 close、cap、returns、volume 作估值或去风险参照系是跨数据集配对的常规手段；若单批次明确要求保持单一内容数据集独立分类，则优先复用该数据集内部自带的价格或市值锚字段。
