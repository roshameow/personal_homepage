本文为量价特征谱系的日内扩展篇（日频 OHLCV 衍生体系与复权数学原理见前篇 《PV 量价衍生数据体系、复权数学原理与在 analyze-dataset 中的应用》（alpha11））。相较于仅刻画“日终结果”的开高低收，日内统计量与市场微结构数据直接刻画盘中交易路径、流动性供需与买卖盘口博弈；下方算子均严格对齐 WorldQuant FASTEXPR 语法（如矢量聚合 vec_avg / vec_sum / vec_max / vec_powersum / vec_stddev / vec_range / vec_choose 与时序算子 ts_entropy / ts_kurtosis / ts_decay_linear 等）。

一、日内 PV 与市场微结构四阶谱系（0→1→2→3 阶）

沿用与日频 PV 完全一致的演化层级划分：0 阶为盘中切片矢量、逐笔快照及平台原生直接提供的日内预汇总字段（未经用户表达式加工）；1 阶为直接作用于 0 阶字段的 vec_* 矢量归约、单步跨字段算术或单层 ts_* 时序变换；2 阶为在 1 阶衍生量之上再做跨日滚动聚合、截面归一化或方差拆分的嵌套特征；3 阶为日内微结构指标与基本面/事件/换手限制的跨特征组合。

图例说明：在零至三阶条目中（不含纯矢量占位符），绿色加粗条目表示已在本地平台实测记录中检索到达标信号（非 SUPER，fitness >= 1.0 且 sharpe >= 1.2；除 CHN 地区外，fitness <= -1.0 且 sharpe <= -1.2 的反向可取负信号亦计为达标）；红色加粗条目表示库中已有实测记录但未达上述门槛；默认颜色为尚未在库中检索到测试记录的理论或扩展方向。

0 阶数据（盘中矢量与平台原生预汇总字段） 一阶数据（直接作用于 0 阶的 vec_* 归约、单步算术与单层 ts_*） 二阶数据（在 1 阶之上的嵌套聚合、截面缩放与方差拆分） 三阶数据（跨维度复合与微结构结构角色）
盘中切片与盘口矢量（VECTOR）
• 区间行情矢量：同一交易日内按 1 分钟/5 分钟切分得到的各区间收盘/均价 p_vec、区间收益率 r_vec（相邻区间价差比）与区间成交量 v_vec
• 买卖报价与深度矢量：盘中各时刻最优买一价 bid_vec、卖一价 ask_vec、盘口中点 mid_vec = (bid_vec + ask_vec) / 2，以及买一/卖一挂单量 bid_size_vec / ask_size_vec、报价不变时买一挂单变化量 d_bid_size_vec
• 逐笔与委托流矢量：每笔成交价 trade_price_vec、每笔成交股数 trade_size_vec、成交方向 side_vec（主动买取 +1、主动卖取 -1）、成交后滞后时刻中点价 mid_fwd_vec、委托订单规模分档矢量 order_size_vec，以及等成交量分桶内的买卖量 buy_vol_vec / sell_vol_vec

平台原生预汇总日内字段（MATRIX）
• 分时量价相关性 (intraday_pv_corr)：平台对单日盘中区间价格（最高价 / VWAP / 买一 / 卖一）与区间成交量预先计算的皮尔逊相关系数，刻画日内“放量上攻/放量下杀”同向度
• 流动性价差基点 (spread_bp)：全天或尾盘 30 分钟按流动性加权的相对买卖价差（以基点 bps 计），直接度量即时盘口冲击成本
• 分时段价格/收益与区间 VWAP：session_close（特定截止窗口末价，如 14:30 时点价）、pre_close_30m_ret / 60m_ret（收盘前 30/60 分钟平均收益）、ask_first_half（按成交量时钟前半程的卖一价均值）、interval_vwap（盘中固定时段成交量加权均价）、mid_ret（按区间权重加权的盘口中点收益）、ext_open / high / low / close / volume（盘前与盘后延伸交易时段 OHLCV）
• 盘口流、主被动成交与竞价做空：盘口买单净流比率（报价不变时买单增量占比）、盘口中点上方主动买量 active_buy_vol、主动吃单买卖量 aggr_buy / aggr_sell、最优卖档新增挂单次数与撤单股数 ask_put / ask_withdraw、开盘/收盘集合竞价（MOO/MOC）撮合价与撮合量 auction_px / auction_vol、含与不含收盘竞价的全天 Tick VWAP（vwap_w_close / vwap_wo_close）、做空成交股数 short_vol、平台预汇总的有效/实现价差 effective_spread / realized_spread，以及 NBBO 最优报价内成交股数 atquote_shares 与 10–29 秒延迟成交股数 shares_10_29s		 vec_* 矢量单日归约
• 分时量价相关（矢量自算）：(vec_avg(p_vec * v_vec) - vec_avg(p_vec) * vec_avg(v_vec)) / (vec_stddev(p_vec) * vec_stddev(v_vec) + 1e-6)（由盘中价格与成交量矢量直接算出的单日皮尔逊相关性，衡量价量盘中同步性）
• 日内振幅与高阶矩：vec_range(p_vec)（日内最高最低价之差）、sqrt(vec_powersum(r_vec, constant=2))（基于分时收益平方和开方的日内实现波动率 RV）、vec_skewness(r_vec) / vec_kurtosis(r_vec)（日内收益分布偏度与峰度，刻画盘中暴涨暴跌尾部风险）
• 委托单规模矢量聚合：vec_avg(order_size_vec)（对交易所分档委托规模编码矢量求均值，捕捉机构大单拆分与散户小单占比结构）
• 成交粒度与盘中中枢：vec_avg(trade_size_vec)、vec_max(trade_size_vec)（平均与最大单笔成交股数，衡量机构扫盘单笔冲击）；vec_avg(mid_ret_vec)、vec_choose(vwap_vec, nth=k)（计算区间中点均收益或提取第 k 个盘中固定时段的均价中枢）
• 盘口深度与三类价差归约：vec_avg(log(bid_size_vec / ask_size_vec))（时间加权盘口挂单厚度对数比，衡量静态买压 vs 卖压）；(vec_avg(ask_vec) - vec_avg(bid_vec)) / vec_avg(mid_vec)（日均报价相对价差）；vec_avg(2 * side_vec * (trade_price_vec - mid_vec) / mid_vec)（有效价差，衡量真实成交相对盘口中点的即时滑点）；vec_avg(2 * side_vec * (trade_price_vec - mid_fwd_vec) / mid_vec)（实现价差，扣除成交后价格继续滑移后的做市净收益）
• 盘口买盘净流 / 主动买量：vec_sum(d_bid_size_vec) / vec_sum(abs(d_bid_size_vec))（买价不变时买单挂单净增比例）、vec_sum(active_buy_vec)（盘口中点上方主动吃单成交量汇总，衡量买方迫切度与真实需求压力）

单步跨字段算术比值 / 差值
• 特定交易时段收盘偏离：session_close / close（特定截止窗口终价相对日终官方收盘价之比，捕捉跨时段或尾盘定价落差）
• 盘初半程卖价-VWAP 偏离：ask_first_half / vwap（成交量时钟前半程卖一价相对全天成交均价之比，衡量盘初卖方溢价与多空情绪强弱）
• Tick 连续交易 VWAP 偏离：(vwap_w_close - vwap_wo_close) / vwap_wo_close（含收盘竞价与不含收盘竞价的全天 Tick VWAP 差异，剥离尾盘集合竞价的集中撮合冲击）
• 盘前 / 盘后延伸时段量价：(ext_high - ext_low) / ext_close、ext_volume / volume（盘前/盘后波幅与成交占比，刻画隔夜信息在非连续时段的提前消化度）
• 主动吃单 vs 被动撤单失衡：(aggr_buy - aggr_sell) / (aggr_buy + aggr_sell)、ask_withdraw / (ask_put + 1e-6)（主动吃单净买压与最优卖档撤单压力）
• 开盘 / 收盘集合竞价撮合（MOO / MOC）：auction_vol / volume、(auction_px - close) / close（开盘/收盘交叉盘撮合量占全天比及竞价溢价，度量机构调仓集中冲击）
• 做空与 NBBO 执行占比：short_vol / volume（衡量盘中空头抛压或做市商库存对冲比例）；atquote_shares / total_shares、shares_10_29s / total_shares（衡量全市场最优报价内即时撮合率与 10–29s 延迟成交占比）
• 逆向选择价差成分：effective_spread - realized_spread（等价于 vec_avg(2 * side_vec * (mid_fwd_vec - mid_vec) / mid_vec)，提取成交后盘口中点向成交方向滑移的价格冲击，即订单流中的知情交易含量）

直接作用于 0 阶的单层 ts_* 变换
• 盘口价差信息熵：ts_entropy(spread_bp, 115)（用中期时间序列熵度量买卖价差的波动无序度：价差稳定有序 vs 流动性骤紧骤松）
• 区间 VWAP 高阶峰度：ts_kurtosis(interval_vwap, 240)（刻画长期区间均价分布的尖峰厚尾与极端定价脉冲）
• 尾盘收益边际变化：ts_delta(pre_close_30m_ret, 5)（刻画尾盘 30 分钟多空力量相对上周的边际增强或衰减）		 对 1 阶衍生量的跨日衰减与累积
• 分时偏离衰减平滑：ts_decay_linear(session_close / close, 5)（对 1 阶特定时段收盘偏离做 5 日线性衰减平滑，捕捉持续性尾盘资金流并降低单日噪声）
• 委托规模多日累积：ts_sum(vec_avg(order_size_vec), 45)（对 1 阶委托单规模均值做近两个月累积，追踪机构 vs 散户订单结构的持续迁移）
• 尾盘动量季度平滑：ts_mean(ts_delta(pre_close_30m_ret, 5), 60)（对 1 阶尾盘周度边际变化再做 60 日均值平滑，观察季度级别尾盘强弱趋势）
• 截面缩放长期累积：ts_sum(group_scale(auction_px / close, bucket(rank(cap), range='0,1,0.1')), 66)（将 1 阶竞价溢价在同市值分桶内缩放到 [0, 1] 后做 66 日累积，捕捉持续性的集中竞价抢筹/抛售）

日内方差分解
• 连续波动与跳跃成分分离：max(vec_powersum(r_vec, constant=2) - 1.57 * vec_sum(abs(r_vec) * abs(r_prev_vec)), 0)（用日内总实现方差减去由相邻区间收益乘积和 bpv 估计的连续扩散方差，分离盘中突发新闻或大单引起的跳跃风险）		 跨维度交互与风险调整
• 微结构熵 × 事件周期交互：ts_decay_linear(group_rank(ts_entropy(spread_bp, 115) / signed_power(ts_rank(event_interval, 66), p), industry), 18)（event_interval 为距财报/事件日历间隔天数，p 为调节时间衰减斜率的指数如 0.68；基本面事件窗口前后盘口混乱度的行业内排序分化更显著）
• 分时量价相关与分桶中性化：group_neutralize(intraday_pv_corr, bucket(rank(cap), range='0,1,0.1'))（对 0 阶原生分时量价相关按市值十分位分桶中性化，剥离风格后提取纯粹日内量价配合度）
• 日内资金流限速组合：ts_target_tvr_delta_limit(signal, active_intraday_flow, lambda_min=0, lambda_max=1, target_tvr=0.1)（用日内盘口活跃成交量 active_intraday_flow 替代日频 adv20 作为换手限速尺，在高冲击时段压降调仓幅度）
• 微结构毒性（VPIN）与滑点门控：vpin = vec_sum(abs(buy_vol_vec - sell_vol_vec)) / vec_sum(buy_vol_vec + sell_vol_vec)（等成交量分桶下的买卖失衡度，预警流动性枯竭与逆向选择风险）；trade_when(spread_bp < ts_mean(spread_bp, 60), signal / (spread_bp + 1e-4), -1)（仅在盘口价差低于 60 日均值时交易并按交易成本折价信号）

二、五类核心微结构指标的金融实质

相比日频表格里的技术指标，日内与盘口微结构统计量的核心价值在于直接观测“价格是怎么形成的”：

  1. 分时量价相关性：
    • 日频的 ts_corr(close, volume, 20) 看的是跨天趋势配合；而日内分时相关看的是单日内部区间价位与区间成交量的同步性（例如价格冲高时是否伴随分时放量，还是无量诱多、低位放量换手）。因为利用了盘中路径信息，它通常与日频反转因子相关性很低。
  2. 价差的三重分解（Quoted / Effective / Realized Spread）：
    • 报价价差（Quoted Spread）：Ask - Bid，代表名义流动性宽度；
    • 有效价差（Effective Spread）：2 * side * (TradePrice - Mid_t)，代表实际成交相对盘口中点的真实滑点；
    • 实现价差（Realized Spread）：2 * side * (TradePrice - Mid_{t+\Delta})，扣除成交后价格继续沿成交方向滑移的价格冲击（Price Impact）。两者之差正是衡量“订单流里有多少知情交易（Informed Trading）”的直接标尺。
  3. 盘口深度失衡与主动流：
    • 仅看静态 vec_avg(log(bid_size_vec / ask_size_vec)) 容易被高频幌骗撤单干扰；结合报价不变前提下的买盘净增量、以及主动吃单（Lifting Ask / Hitting Bid）与最优档撤单比例，能更干净地分离真实买压与假挂单。
  4. 分时段动量与集合竞价（MOO / MOC）：
    • 成熟市场大量指数调仓、机构再平衡集中在收盘集合竞价（MOC）完成，导致盘中连续交易 VWAP与含收盘竞价的终值 VWAP、收盘前 30 分钟收益率之间出现结构性定价扭曲，往往在次日或周度呈现均值回归。
  5. 盘口时序熵（ts_entropy(spread_bp, d)）：
    • 比起单纯看价差大小（小盘股天生价差大），对相对价差计算时间序列熵反映的是流动性状态的确定性与混乱度，再与事件日历周期做比值，能有效刻画事件窗口前后的市场微观分歧。

三、在 analyze-dataset 与策略研究中的实践要点

  1. 与日频行情的角色分工：
    • 在 analyze-dataset 的多通道协同中，日内微结构字段既可以作为独立低相关 Alpha 源（尤其是分时相关性、盘口价差熵、集合竞价偏离），也可以替代日频 adv20 充当更精细的流动性分桶基准、换手限速尺（ts_target_tvr_delta_limit）或滑点门控条件（trade_when）。
  2. 数据清洗与降频平滑：
    • 盘口与延伸时段（盘前/盘后）字段容易在停牌、极端小盘股上出现 NaN 或尖刺：实操中通常需要先做 ts_backfill 补齐、对 VECTOR 类型（如分档委托/分时数组）用 vec_avg / vec_sum / vec_powersum 归约为标量，再配合 ts_decay_linear 或 ts_sum 做跨日平滑，避免因单日微观噪声引发过高的换手率（Turnover）。
