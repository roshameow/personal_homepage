一、News & Social Media 衍生数据三阶谱系（0→1→2 阶 + WorldQuant FASTEXPR 对齐）

舆情类数据更新快、信噪比低、高度非对称且常带事件稀疏性，严格按三阶结构拆解：0 阶为媒体新闻流、NLP 情绪分、社交热度与电话会语调原始字段；1 阶为单步矢量归约（vec_avg / vec_sum / vec_count）、流÷存量强度（密度比）、正负极端净额及单层 ts_* 注意力脉冲/平滑；2 阶为利用高信噪比舆情事件驱动门控（trade_when）、事件锚定止损、热度过滤反转及对系统风险正交剥离。

图例说明：在一至二阶衍生指标中，绿色加粗条目表示已在本地平台实测记录中检索到达标信号（非 SUPER，fitness >= 1.0 且 sharpe >= 1.2；除 CHN 地区外，fitness <= -1.0 且 sharpe <= -1.2 的反向可取负信号亦计为达标）；红色加粗条目表示库中已有实测记录但未达上述门槛；默认颜色为尚未在库中检索到独立测试记录的理论或扩展方向。

0 阶数据（新闻流、社媒、文本与关注度字段） 一阶数据（矢量归约、流/存强度、净情绪与单层 ts_*） 二阶数据（事件门控、热度反转、正交剥离与止损角色）
专业新闻流与事件影响力
• 事件影响力与复合情绪：news_impact（新闻对股价影响预测值）、news_css（复合情绪分）、news_bee（财报新闻正/中/负打分 -1/0/1）、news_bam（风险/事件新闻情绪分）
• 新闻关注度与交易冲击：news_ticks（市场/个股变价与报道活跃次数）、news_open_vol（开盘成交量锚）、news_session_range（新闻期高低波幅）、news_mention_freq（媒体提及频率）、post_news_ret_4l（新闻后股价触及阈值耗时）
• 宏观与多通道 NLP 新闻：macro_pos_freq / macro_neg_sc（宏观事件正负提及频次/情绪）、headline_sent（短评头条情绪）

文本 NLP 情绪、网页热度与电话会
• 多维文本概率与置信度：nlp_pos_mean、nlp_neut_mean、nlp_neg_max、nlp_conf_up / low（财报/新闻/申报文本的正中负情绪及置信边界）
• 网页与品牌关注度排名：web_rel_pop（相对网页流行度）、web_avg_rank（访问排名）
• 财报电话会语调：call_overall_sent、call_qa_sent、call_pres_sent（整体语调、问答环节 Q&A 与预先陈述段情绪）

社交媒体与散户讨论
• 社媒净情绪与讨论热度：social_sent（净情绪 -1~1）、social_buzz（相对讨论声量/关注度）
• 行为心理细分矢量：social_longshort（看多 vs 做空词频净值）、social_emotion_vs_fact（情绪化 vs 事实性表达）、social_trust / conflict / stress / optimism（信任、分歧、压力、乐观度）
• 市场基准：close、returns、cap、volume、adv20、spy_corr_60d（与大盘 60 日相关性）		 矢量归约与注意力度量
• 新闻频次密度与开盘量归一化：-winsorize(ts_mean(news_ticks / (news_open_vol + 1e-6), 240), std=4)（用开盘成交量归一化新闻触发跳动次数，剥离大盘流动性偏差后捕捉长期喧嚣反转）
• 新闻评论热度高点时间距离：ts_arg_max(pasteurize(vec_count(headline_sent)), 22)（近一月内头条评论数量达到峰值距今天数，定位新闻热点发酵还是退潮期）
• 多日平均新闻情绪与冲击力：ts_rank(vec_avg(news_bee), 22)、ts_mean(news_impact, 60)（对离散新闻事件做短/中期均值或分位压缩，滤除单篇通稿噪声）
• 宏观事件正负极性比：vec_sum(macro_pos_freq) / (vec_range(macro_neg_sc) + 1e-6)（正面事件密度除以负面情绪极差，刻画宏观净利好强度）

网页热度与文本情绪演化
• 网页流行度二阶差分 (rel_pop)：-ts_delta(ts_delta(ts_median(ts_backfill(vec_stddev(web_rel_pop), 120), 120), 240), 240)（度量网页关注度离散度的同比加速度反转）
• NLP 中性/极值情绪与电话会总体语调：ts_backfill(nlp_neut_mean, 60)、ts_backfill(call_overall_sent, 120)（提取新闻与电话会文本的基础语调底座）
• 电话会陈述与 Q&A 语气差：call_qa_sent - call_pres_sent、ts_delta(call_overall_sent, 63)（剔除公关套话，专注管理层临场回答的信心衰减与环比语气走弱）
• 情绪分布负面长尾偏度 (tone_skew)：ts_skewness(news_css, 60)（探测丑闻爆发前舆论从对称走向极端负长尾的相变）

社交媒体热度与心理词频能量
• 社媒多空词频活跃能量：ts_std_dev(ts_sum(power(ts_backfill(vec_count(social_longshort), 22), 2), 60), 60)（多空讨论次数的累积二阶能量与波动率，衡量散户情绪狂热程度）
• 社媒绝对讨论量反转 (buzz_rev)：-group_rank(social_buzz, subindustry)（散户极端刷屏讨论度往往伴随短期买盘见顶）
• 社媒情绪波动 × 大盘解耦：zscore(ts_std_dev(ts_backfill(social_sent, 60), 60))（持续关注与情绪起伏，需排除与大盘同涨同跌的 Beta 股）
• 新闻事件波动最大时间距离 (news_range_arg)：ts_arg_max(ts_backfill(news_session_range, 20), 60)（最大新闻波动发生距今天数，判定消息冲击是否已充分消化）		 新闻/情绪条件门控 (trade_when)
• 新闻影响门控方向收益：ts_mean(if_else(news_impact > 0, returns, nan), 60)；trade_when(ts_rank(vec_avg(news_bee), 22) > 0.8, group_rank(ts_decay_linear(ts_delta(tx_cost, 5), 20), country), -1)（只在正向财报新闻或高情绪置信窗口内激活主信号，其余时间保持空仓或冻结调仓）
• 低社媒喧嚣过滤反转 (buzz_gate)：trade_when(group_rank(social_buzz, subindustry) < 0.5, group_neutralize(scale((high + low) / 2 - close), group_cartesian_product(country, subindustry)), -1)（散户过度热议时噪音大，仅在冷清低 buzz 股中交易日内中点反转效果极稳）
• 新闻流动性与低指数相关过滤：trade_when(volume > adv20, news_signal, -1)、trade_when(spy_corr_60d < 0.4, social_vol_signal, spy_corr_60d > 0.6)（确保消息确实伴随放量定价，且剔除受大盘 Beta 主导的标的）

舆情驱动的锚定止损与风险正交
• 社媒情绪触发点位止损：close_at_event = trade_when(not(vec_avg(social_sent) > 0.1), close, -1); if_else(abs(close - close_at_event) / close > 0.1, nan, pv_reg_signal)（当情绪转弱/异动且股价自锚定日偏离超 10% 时强制平仓止损）
• 新闻头条高峰 × 短期反转耦合：ts_arg_max(pasteurize(vec_count(headline_sent)), 22) * -ts_returns(close, 5)（新闻讨论热度达峰时间距离越远，叠加 5 日超跌反转越可靠）
• 网页热度变化 × 做空/风险正交：regression_neut(ts_max_diff(short_interest, 70), ts_max_diff(web_avg_rank, 222))（从机构做空拥挤度中剥离散户网页关注度影响，提纯知情做空信号）

二、新闻与社交媒体数据的四大行为金融特性

  1. 极低信噪比陷阱与“关键事件”过滤
    • 直接拿网页新闻正负分做“正面买、负面卖”往往表现极差，因为大量报道只是自动化行情快报和毫无增量信息的通稿复读。有效策略通常要把原始新闻当作条件门控（trade_when 仅在事件发生期启用量价/估值信号），或做中期滚动平滑（ts_mean(..., 22~60)）滤掉瞬时噪音。
  2. 注意力经济与“聚光灯消退后的反转”
    • 当一只股票连续多日新闻提及数或 social_buzz 冲至行业前排时，往往意味着散户买盘已集中透支；因此许多高分表达式反而在 social_buzz 处于低分位时交易微结构反转，或者在新闻热度见顶回落时做空过度关注标的。
  3. 损失厌恶与情绪偏度的非对称性
    • 利空消息（丑闻、监管处罚、产品召回）引发恐慌踩踏的速度远快于利好消息带来的估值抬升。仅看均值容易被中和，关注负面长尾极值、情绪偏度（ts_skewness）及心理维度中的 conflict / stress 分量更有区分度。
  4. 财报电话会“书面陈述 vs 临场问答（Q&A）”撕裂
    • 预先写好的陈述稿往往经过公关修饰，真正暴露管理层底气的是分析师尖锐提问下的 Q&A 语调变化以及情绪环比退潮（哪怕绝对值仍为正，相比上季度转保守也是重要的风险提示）。

三、在 analyze-dataset 中的实战应用

  1. 原始流/事件字段必须先构造密度与净值（通道② / 通道③）
    • 按 economics_pairing_principles.md：新闻数、提及次数、点赞数等原始计数绝对值高度正相关于公司市值（大盘股天然新闻多），不能直接排横截面。必须走通道②做“流÷存量”归一化（如 news_ticks / news_open_vol 或 mention_count / cap），或跨量纲加权（如 数量 × 情感强度）。
    • 对同量纲互补字段（positive ↔ negative、buy ↔ sell、pres ↔ qa），直接走 通道③ 极性/快照配对（spread），不再另建冗余中间字段。
  2. 最核心的两大落地角色（通道④ event_regime & 跨频过滤）
    • 角色 A（事件门控 trade_when）：用新闻情绪分位、宏观事件状态或低社媒喧嚣过滤主策略，往往比用舆情单独做多空更能大幅抬高夏普与降低回撤。
    • 角色 B（风险与大盘解耦）：对社媒高波动标的搭配 spy_corr_60d < 0.4 或 regression_neut 剥离大盘与拥挤度干扰。
