{%- comment -%} Optional two-level theme tree with expandable notes. Posts declare front matter `theme` as either a single value or a list; each value is "Parent" or "Parent/Child". Obsidian properties sync through unchanged. "Parent / Child" spacing is normalized, so hand-written notes land in the same node. On the home page, each theme/sub-theme can be directly expanded to display the note subtitles (or title if no subtitle), linking directly to each note.
