## 一、Fundamental 基本面衍生数据三阶谱系（0→1→2 阶 + WorldQuant FASTEXPR 对齐）

相较于日频量价存在明显的多层滚动统计嵌套，基本面数据多由 0 阶原生财务科目经单步比率或直接时序重标演化而来，因此合并为**三阶谱系**边界最清晰：**0 阶**为三张财务报表及附注的原生会计科目（加基础股价/市值参照）；**1 阶**为直接围绕 0 阶科目展开的财务比率、市场估值锚、应计/回款质量检验与历史自我重标（含 `ts_backfill` 填充）；**2 阶**为多因子质量共振、风险残差剥离、经典经济学定价模型（杜邦、戈登、PEG）及基本面状态门控角色。

> 图例说明：在一至二阶衍生指标中，<span style="color: #059669; font-weight: 600;">绿色加粗条目</span>表示已在本地平台实测记录中检索到达标信号（非 SUPER，`fitness >= 1.0` 且 `sharpe >= 1.2`；除 CHN 地区外，`fitness <= -1.0` 且 `sharpe <= -1.2` 的反向可取负信号亦计为达标）；<span style="color: #dc2626; font-weight: 600;">红色加粗条目</span>表示库中已有实测记录但未达上述门槛；默认颜色为尚未在库中检索到独立测试记录的理论或扩展方向。

| 0 阶数据（原生财务科目与市场参照） | 一阶数据（财务比率、估值锚、质量检验与历史重标） | 二阶数据（多维复合、经济学模型与门控角色） |
|---|---|---|
| **利润表（Income Statement）**<br>• `sales`：营业收入<br>• `cogs`：营业成本<br>• `gross_profit`：毛利润（`sales - cogs`）<br>• `sga`：销售及管理费用<br>• `rd_expense`：研发费用<br>• `ebit` / `operating_income`：息税前/营业利润<br>• `interest_expense`：利息/资本化利息费用<br>• `pretax_income`：税前利润<br>• `income_tax`：所得税费用<br>• `income`：经常性净利润<br>• `eps`：每股收益<br><br>**资产负债表（Balance Sheet）**<br>• `assets`：总资产<br>• `current_assets` / `cash_st`：流动资产 / 现金及短期投资<br>• `receivables` / `inventory`：应收账款 / 存货<br>• `goodwill` / `intangible_assets`：商誉 / 无形资产<br>• `liabilities` / `current_liabilities`：总负债 / 流动负债<br>• `debt_st` / `debt_lt` / `debt`：短期债务 / 长期债务 / 总债务<br>• `deferred_revenue`：递延收入（预收/订阅合约待确认收入）<br>• `retained_earnings`：留存收益（累计未分配利润）<br>• `equity` / `bookvalue`：股东权益 / 账面净资产<br><br>**现金流量表与分红**<br>• `cashflow_op`：经营活动现金流量净额<br>• `capex`：资本开支<br>• `free_cashflow`：自由现金流（`cashflow_op - capex`）<br>• `dividend_paid`：现金股利支出<br><br>**附注、人效与市场参照**<br>• `employees`：员工人数<br>• `fair_value_assets` / `fair_value_liab`：资产/负债公允价值附注<br>• `fx_adj`：汇兑损益调整<br>• `monthly_sales_growth_vec`：月度销售增长历史矢量（`VECTOR`）<br>• 基础行情锚：`close`、`cap`、`sharesout`、`enterprise_value`（`cap + debt - cash_st`）及 `sector` / `industry` / `subindustry` | **盈利能力与经营效率比**<br>• <span style="color: #059669; font-weight: 600;">毛利资产比 (`GPA` / `gross_margin`)</span>：`gross_profit / assets`、`gross_profit / sales`（每单位总资产创造的毛利与产品毛利率，衡量核心产品定价力且抗折旧操纵）<br>• <span style="color: #059669; font-weight: 600;">营业资本回报 (`ROA` / `ROIC` / `ROCE`)</span>：`ebit / assets`、`operating_income / equity`、`income / (debt + equity - cash_st)`（衡量全部资产或投入资本的实际盈利回报率）<br>• <span style="color: #059669; font-weight: 600;">净利率与回款效率 (`net_margin` / `ebit_rec`)</span>：`income / sales`（营收转化净利润效率）；`ebit / (receivables + 1e-6)`（营业利润相对应收账款的周转支撑度）<br>• <span style="color: #059669; font-weight: 600;">现金流含金量 (`ocf_sales` / `fcf_assets`)</span>：`cashflow_op / sales`、`free_cashflow / assets`、`cashflow_op / fair_value_assets`（检验账面利润是否有真实经营现金回款与公允资产支撑）<br>• **盈利 / 资本开支比 (`ebit_capex`)**：`ebit / (capex + 1e-6)`（衡量每单位资本开支换取的营业利润，过低往往预示重资产低效扩张）<br>• <span style="color: #059669; font-weight: 600;">费用效率与人效 (`op_sga` / `rev_per_emp`)</span>：`income / (sga + 1e-6)`（净利润相对销管费用的转化效率）；`sales / (employees + 1)`（人均创收能力）<br>• <span style="color: #dc2626; font-weight: 600;">研发投入强度 (`rd_intensity`)</span>：`rd_expense / (sales + 1e-6)`（研发费用占营收比，衡量长期技术壁垒投入强度）<br>• <span style="color: #059669; font-weight: 600;">汇兑盈利稳健性 (`fx_profit_ratio`)</span>：`ebit / (abs(fx_adj) + 1e-6)`（衡量核心经营利润相对汇率折算损益扰动的纯净度）<br><br>**估值倍数与市场价格锚定**<br>• <span style="color: #059669; font-weight: 600;">盈利收益率 (`EP` / `PE_inv`)</span>：`eps / close`、`income / cap`（市盈率倒数，单位市值对应的盈利回报）<br>• <span style="color: #059669; font-weight: 600;">市销率倒数 / EV 营收比 (`SP` / `EV_Sales`)</span>：`sales / cap`、`enterprise_value / (sales + 1e-6)`（按公司总营收规模对市值或企业价值锚定）<br>• <span style="color: #059669; font-weight: 600;">自由现金流估值 (`FCF_EV` / `CF_Price`)</span>：`free_cashflow / enterprise_value`、`cashflow_op / cap`（真实自由现金流对企业总价值或市值的贴现率）<br>• <span style="color: #059669; font-weight: 600;">账面市值比 (`BM` / `BVPS_P`)</span>：`bookvalue / cap`、`equity / cap`（净资产账面价值相对总市值的安全边际）<br>• <span style="color: #059669; font-weight: 600;">股息率与分红 (`dividend_yield`)</span>：`dividend_paid / cap`（现金分红占总市值比例）<br><br>**资产负债结构与偿债安全垫**<br>• <span style="color: #059669; font-weight: 600;">财务杠杆与偿债安全垫 (`leverage` / `cash_to_debt`)</span>：`liabilities / assets`、`debt / assets`（资产负债暴露）；`-debt_lt / (cash_st + 1e-6)`、`income - debt_st`（长短债现金覆盖与经常利润扣减短期债务后的盈余）<br>• <span style="color: #059669; font-weight: 600;">流动结构与去库存效率 (`curr_surplus` / `inv_inv`)</span>：`(income - current_assets) / (current_assets + 1e-6)`、`income / (current_liabilities + 1e-6)`（短期资产占用与流动负债覆盖）；`1 / (inventory + 1e-6)`（低存货积压偏好）<br>• <span style="color: #059669; font-weight: 600;">商誉风险与资本开支率 (`goodwill_sales` / `capex_sales`)</span>：`-goodwill / (sales + 1e-6)`、`capex / (sales + 1e-6)`（预警并购高商誉减值风险与观测资本支出周期）<br>• <span style="color: #059669; font-weight: 600;">融资成本变化 (`interest_diff`)</span>：`ts_max_diff(winsorize(ts_backfill(interest_expense, 120)), 252)`（当前利息支出相对过去一年峰值的回落幅，反映融资压力边际缓解）<br>• **净营运资本比 (`wc_ratio`)**：`(current_assets - current_liabilities) / assets`（短期流动资产净缓冲占总资产比）<br><br>**盈利质量背离与时序自我基线**<br>• <span style="color: #dc2626; font-weight: 600;">Sloan 应计质量 (`accruals`)</span>：`(income - cashflow_op) / (assets + 1e-6)`（账面净利润减经营现金流占总资产比：应计过高往往预示靠应收/存货虚增利润，未来易均值回归）<br>• **应收/CapEx 质量检验 (`rec_sales_gap` / `capex_rev_conv`)**：`ts_delta(receivables / (sales + 1e-6), 252)`（应收增速长期跑赢营收则提示回款恶化）；`ts_delta(sales, 252) / (ts_mean(capex, 252) + 1e-6)`（检验新增资本开支是否转化为营收增量）<br>• <span style="color: #059669; font-weight: 600;">每股留存收益增长与消耗</span>：`ts_delta(retained_earnings / sharesout, 60)`（剔除股本稀释/回购影响后的每股内生资本沉淀变化）；`-ts_rank(ts_backfill(retained_earnings, 120), 250)`（留存收益显著下降，需结合分红率判断是否派息）<br>• <span style="color: #059669; font-weight: 600;">历史自我重标与 5 年估值偏离</span>：`ts_zscore(ts_backfill(ebit, 120), 120)`、`ts_zscore(ts_backfill(operating_income / receivables, 120), 120)`、`ts_backfill(ep_ratio, 120) - ts_mean(ts_backfill(ep_ratio, 120), 1260)`（“和公司自身过去比”，削弱跨行业会计口径差异）<br>• <span style="color: #059669; font-weight: 600;">销售动量信息比与同比滞后</span>：`ts_ir(vec_sum(monthly_sales_growth_vec), 252)`（持续稳定放量）；`ts_delay(winsorize(ts_backfill(-1 / sales, 120)), 240)`（取去年基线避开当期财报公布冲击）<br>• <span style="color: #dc2626; font-weight: 600;">递延收入趋势斜率 (`dr_slope`)</span>：`ts_regression(ts_backfill(deferred_revenue, 120), ts_step(1), 252, rettype=2)`（用时间回归斜率刻画订阅/预收类业务未确认收入的储备增速） | **双重估值交叉与多维质量共振**<br>• <span style="color: #059669; font-weight: 600;">双重估值比率交叉 (`FCF_EV_Sales` / `PCFR_EV_Sales`)</span>：`ts_zscore(ts_backfill((free_cashflow / sales) * (sales / enterprise_value) / (enterprise_value / sales), 120), 120)`、`ts_quantile(winsorize(ts_backfill(-(cap / cashflow_op) / (enterprise_value / sales), 120), std=2), 66)`（现金流估值与营收估值交叉，等价于用自由现金流利润率校正 PS 错配）<br>• <span style="color: #059669; font-weight: 600;">资产质量 × 低库存 × 低商誉共振</span>：`rank(income / assets) + ts_rank(1 / (inventory + 1e-6), 252)`；`-zscore(ts_backfill(goodwill / sales, 65)) + rank(capex / sales) + rank(debt / assets)`（同时把关资产回报、周转效率与资产负债防线）<br>• <span style="color: #059669; font-weight: 600;">综合财务健康度 (`F-Score`)</span>：将盈利为正、经营现金流为正、ROA 提升、应计为负、杠杆下降、流动比率上升、未增发摊薄、毛利率及周转率提升这 9 项打分聚合（筛选高安全边际质量股）<br><br>**风险残差剥离与跨风格耦合**<br>• <span style="color: #059669; font-weight: 600;">基本面因子对风险暴露正交 (`fnd_resid`)</span>：`ts_regression(ts_zscore(ts_backfill(roce, 120), 252), risk_exposure, 252, rettype=0)`、`ts_regression(ts_quantile(ts_backfill(pretax_income, 120), 252), risk_exposure, 252, rettype=0)`（用回归剥离市场风格与风险模型暴露，保留特异基本面 Alpha）<br>• **估值与动量长期耦合**：`-ts_corr(ts_backfill(value_score, 66), ts_backfill(mom_score, 66), 756)`（长周期内基本面估值与价格动量的共振或背离程度）<br><br>**基本面状态门控（`trade_when`）与行业分级**<br>• <span style="color: #059669; font-weight: 600;">基本面门控风险因子</span>：`trade_when(ts_backfill(rd_expense, 120) > 0, group_neutralize(signal, industry), -1)`（仅对存在实质研发投入或正现金流的公司开启信号暴露，过滤空壳与低质噪声）<br>• **分规模运营效率分组**：`group_rank(ebit / assets, subindustry) - group_neutralize(ts_mean(ebit, 210) / ts_mean(capex, 210), subindustry)`（配合市值分桶 `bucket(rank(cap), range='0,1,0.1')` 区分大盘稳健运营与小盘高扩张）<br><br>**经典经济学模型配对（`actual` vs `model`）**<br>• **杜邦拆解与偿债联动**：`ROE = (income / sales) * (sales / assets) * (assets / equity)`（先看高 ROE 来源是净利率、周转率还是高杠杆，再搭配 `ebit / interest_expense` 过滤高利息风险企业）<br>• **戈登增长定价偏离 (`Gordon`)**：`r = rf + beta * (rm - rf)`，`g = (1 - dividend_paid / income) * (income / equity)`，`P_model = dividend_paid / (r - g + 1e-4)`（对比 `ts_mean(close, 21)` 与 `P_model` 衡量成熟派息股估值偏差）<br>• **PEG 增长调整估值**：`(close / eps) / (100 * ts_delta(eps, 252) / (abs(ts_delay(eps, 252)) + 1e-4))`（用盈利增速校正静态市盈率） |

## 二、财务报表数据的四大工程特性与避坑指南

不同于日频量价每天连续更新，基本面数据受限于**披露频率低、行业会计口径差异大、分母极值多**三大结构特征，直接套用 PV 算子极易踩坑：

1. **PIT（Point-in-Time）发布时滞与 `ts_backfill` 刚性需求**
   - 季报/年报在绝大多数交易日上是缺失值（`NaN`），若不先调用 `ts_backfill(x, 120~252)` 将最近一次已发布财报向前填满，截面 `rank` 会丢失大量股票，并在财报公布当天引起换手率骤增。
   - 若字段包含财报期结束日与实际披露日两种时间戳，回测务必严格使用 **Point-in-Time（实际披露日生效）** 口径，防止用尚未公告的财务数据产生未来函数。
2. **季报 vs 年报口径与同比对齐（避免季节性假信号）**
   - 零售、旅游、建筑等行业存在显著四季强周期；对未做 TTM 年化的单季字段做短期 `ts_delta(x, 60)` 会把季节性旺季误判为增长拐点。比较财务增速应优先使用 **TTM 字段** 或 **一年期同比步长**（`ts_delta(..., 252)` / `ts_delay(..., 240)`）。
3. **跨行业量纲不可比：优先“行业中性 + 自身历史比”**
   - 金融/地产与软件/医药的 `liabilities / assets`、`inventory`、`capex` 天生不在同一坐标系。直接全市场 `rank` 往往等价于重仓或做空整个行业，实操中通常需要先做 `group_neutralize(..., industry / subindustry)`，或者先用 `ts_zscore(..., 120~252)` 让公司与自己过去几年的基线相比。
4. **分母归零、负值符号翻转与 `winsorize` 去极值**
   - 像 `ebit / capex`、`income / debt_st`、`cash_st / debt_lt` 这类比率，当分母趋近 `0` 或分子分母同时为负时（例如亏损企业除以负净资产得正 PE），排序逻辑会彻底反转。稳健写法是先用 `winsorize(..., std=3/4)` 去极值，并用 `if_else(denom > 0, ...)` 或对分母加保护与方向约束。

## 三、在 `analyze-dataset` 中的实战应用（四通道协同）

结合 `.agents/skills/analyze-dataset` 的研究框架与经济学配对原则（`economics_pairing_principles.md`），基本面数据集在四通道中的路由策略如下：

1. **先判数据集“合成度”，决定是否走通道②（Composite 中间字段）**
   - 若目标数据集本身已提供复合估值/利润率字段（如自带 `PE`、`NetMargin`、`CashFlow/Sales`），可直接进入通道①单算子加工与通道③配对；
   - 若数据集以**原始三大表分列科目**为主（只有孤立的 `income`、`assets`、`debt`、`capex`、`sales`），绝对规模直接排序受市值主导极强，必须先进入 **通道②（Composite）**：构造盈利质量比（`ebit/assets`、`cashflow_op/sales`）、估值倒数（`eps/close`、`sales/cap`）、偿债比率（`cash_st/debt_lt`、`liabilities/assets`）或每股化特征（`retained_earnings/sharesout`），再将构造产物送入通道①（`ts_backfill` → `ts_zscore` / `group_rank`）完成标准化。
2. **通道③五大经济学配对范式**
   - **自身历史偏离（`exceed`）**：当前估值或盈利指标 vs 自身 5 年均值基线（`ts_mean(..., 1260)`），消除长期行业估值折溢价；
   - **质量交叉检验（`spread` / 错配比）**：净利润 vs 经营现金流（应计质量）、营收增速 vs 应收增速（回款质量）、自由现金流 vs 资本开支（扩张收获拐点）、自由现金流估值 vs 营收估值；
   - **模型类配对（Model-Based）**：按杜邦分析（利润率/周转/杠杆）、戈登增长（`D / (r - g)`）与 PEG 构造理论内在价值 `model data`，再与市场实际价格 `actual data` 比较偏离；
   - **风险残差投影（`projection`）**：用 `ts_regression` 将基本面指标投影到风险因子暴露（Beta/行业/波动率）上取残差，剔除隐含风格倾斜；
   - **基础元素参照池（`base_fields.py`）**：当基本面数据集缺少 `close` / `cap` / `sharesout` 时，可按角色从基础行情池引入以构造 `EP`、`SP`、`BM`（注：若该批次旨在冲击单数据集独立分类，则优先使用目标数据集内部自带的市值/企业价值/股价字段）。
3. **通道④组合与跨频门控定位**
   - 基本面因子天然换手极低（常 `< 0.10`），在通道④中既适合通过 `ts_backfill(..., 120~252)` + `ts_zscore` / `ts_decay_linear` 作为稳健多因子底座，也极适合通过 `trade_when(rd_expense > 0, ...)`、`trade_when(cashflow_op > 0, ...)` 充当高频量价/舆情信号的基本面质量门控，过滤财务脆弱或无真实经营支撑的标的。
