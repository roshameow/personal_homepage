在这套体系中，AI Agent 既被用来作为**“出题人（Author/Designer）”**构建评测基准，又被作为**“做题人（Solver/Candidate）”**执行高难度业务任务。而令人惊叹的是：**出题 Agent 的盲区、做题 Agent 的弱点，以及如何真正设计出一道能难住它的工业级好题，三者构成了一个严丝合缝的认知闭环。**

本文将这数千小时沉淀的第一手实战经验，系统性梳理为上、中、下三篇。

# 上篇：命题构建端（出题 Agent）易犯的七大系统性错误

当让 AI Agent 负责“设计题目、构造长文素材、编写评分规则与金标准”时，它最容易陷入以下七大陷阱：

## 1. “消歧义 vs 难度”的结构性死锁：把“消除歧义”做成“答案外泄”，把“追求难度”做成“故意模糊”
- **消歧义导致难度瞬间崩塌**：当平台质检打回要求“消除附件核对范围歧义、明确口径”时，Agent 的第一反应是把所有核对要点直接做成清单写进题面 Prompt。题面瞬间变成了保姆级操作清单（SOP），做题模型按清单顺藤摸瓜逐项抄写，得分率从 50% 暴涨到 90%+，直接击穿 ≤60% 的难度天花板导致题目废弃（如谛听 178801 申诉修改惨案）。
- **故意依赖题面歧义压分**：反过来，当 Agent 发现模型得分过高想要“加难”时，它的本能是在题干里挖语言陷阱——故意漏写范围、混淆术语、给出互相矛盾的指令。平台专家对此的终裁是：“禁止依赖题面歧义制造难度；消除歧义后模型分数必然上升，说明此前失分纯粹是因为题面瑕疵而非专业难度”（如谛听 167160 终裁）。
- **根因**：无法区分**“任务说明的清晰度（Specification Clarity）”**与**“内在决策的深层复杂性（Cognitive Complexity）”**。

## 2. 拟真幻觉与脱敏自欺：用概率生成冒充客观事实，用格式改动伪装材料脱敏
- **凭空捏造公文与实体**：为了制造核对冲突，Agent 凭空撰写了多份看似极规范的材料，甚至编造了“上证公函〔2025〕1426号关于衡达智能的问询函”。联网核验发现 A 股根本没有这家上市公司，文号纯属捏造，被质检以“虚构材料、缺乏真实业务来源”一票否决。
- **“形式脱敏”的形式主义自欺**：以为只要修改 Word/Excel 的 `core.xml` 属性、换表头底色、将姓名改成“张某某/XX公司”，就叫“真实材料脱敏”。然而内容缺乏实际业务自然沉淀的脏数据与时序摩擦。“清除痕迹≠修改内容，脱敏≠重制”，AI 合成材料永远无法满足真实工作原件要求。
- **“抽空输入”的主观脑补（Xpert L20）**：Agent 宣称“已将附件中的关键人日排班数据全部抽空以增加难度”，但人工复查原件第 3 页清清楚楚列着完整人日表格，Agent 的操作全凭幻觉。
- **根因**：习惯用“概率生成文本”替代“物理真实性”，缺乏对商业与监管一手凭据的敬畏。

## 3. 金标准（Ground Truth）的近亲繁殖：抄袭模型输出当标答，缺乏独立复算闭环
- **近亲繁殖的标答污染（Xpert L19）**：更新标答核心数据时，Agent 不去原始几十页的 PDF 报表中手工端到端复算，而是图省事直接截取“上一个受试模型生成的答案摘要（Model Summary）”作为标准答案保存。导致受试模型的局部错误被固化为金标准，引发后续多轮迭代全盘算错（00516 两次算错根因皆在此）。
- **金标准无法通过自身 Rubrics**：Agent 构造出的参考答案，拿自己写的规则跑一遍，得分率竟然只有 70%；甚至参考答案为了凑出正确数值，在毫无题面提示的情况下擅自引入了 Shapley 归因等高阶反事实假设，公然违背公开评测契约。
- **根因**：大模型的**捷径偏好（Shortcut Bias）**，缺乏从原始一手底表进行独立溯源复算（Independent Recomputation）的工程纪律。

## 4. 机械工作量错觉：把“体力计算与表格堆叠”错当成“专家智力难度”
- **无休止的同构扩张**：在估值分析中拼命加商誉表、权益桥、分期付款矩阵；在核对题中不断追加年份、加残差表、加 20 个交叉分桶。
- **前沿模型的无情反杀**：现代 LLM 最擅长的就是确定性规则下的机械算术与跨表提取！任凭 Agent 塞进 10 张勾稽表，受试模型依然能以 90%~100% 正确率轻松算完。题目不仅没变难，反而变得臃肿昂贵。
- **根因**：将人类的**认知疲劳与视觉厌烦**误当成机器的智力瓶颈。

## 5. 评分规则（Rubrics）的粗暴建模：非原子化捆绑与负向镜像双罚
- **非原子化打包（Non-atomic Compounding）**：一条规则里捆绑“正文与附件编号一致”+“标题与概要时间一致”，或塞入 10 个事实要件。模型答对前一半漏掉后一半时无法客观判分，被 AI Checker 判 Major Defect 打回。
- **正负向镜像双罚（Mirror Penalty）**：正向加分项设“若分析出某风险得 4 分”，负向扣分项又加“若遗漏该风险扣 4 分”。重复判罚破坏了分值体系守恒，直接将弱模型扣成负分。
- **规则上限与穷举深度的矛盾**：平台限制 Rubrics ≤ 50 条，Agent 拆分原子化后条数暴涨，为不超标随手删掉高区分度的穷举考点，导致模型得分率失控反弹。
- **根因**：缺乏**形式化评价理论（Measurement Theory）**素养，习惯写感性评语而非正交断言。

## 6. 环境与传输故障的误判：把“系统暴毙”当成“模型不会做”
- **把传输截断当成低分达标**：受试模型测出 37.5 分，Agent 兴奋汇报“难度达标（≤50%）”，排查发现是 HTTP 传输直接丢了最后 4 行核心输入导致模型异常退出，且 22 项定性规则根本没跑。
- **把配额消耗当成考试成绩**：日志记录“17.8%”，Agent 望文生义当成“模型得分 17.8%”，实际上那是“单次调用消耗了 17.8% 的云电脑额度”。
- **把容器崩溃当成专家难度**：受试模型因环境依赖缺失或网络超时报 0 分，Agent 顺水推舟将其写为“题目难度极大、模型无法作答”的证据。
- **根因**：**确认偏误（Confirmation Bias）**，拿到符合预期的数字就不加求证地迎合汇报。

## 7. 版本因果链断裂：跨代拼接、幽灵打分与调试痕迹污染
- **拿新规则批改旧答卷的“跨代幽灵”**：题面已从 8 页改成 9 页，但后台绑定的仍是旧版 8 页模型产物。Agent 拿着 9 页评分规则去改 8 页旧答卷，得出极其荒谬的超低分（PPT 168373 早期惨剧）。
- **思考路径的内部调试污染**：向平台提交的正式“业务思考路径”里，赫然打印着 `Round 2 修复核对 / 字数契约 / Rubrics 50条限制 / Checkpoint` 等自动化脚本调试日志，被质检安全审查一票否决。
- **表单字段名与物理含义倒错**：平台长文材料框对应历史字段名 `systemPrompt`，任务提示词对应 `userPrompt`，Agent 仅凭字面语义屡次颠倒装填。
- **根因**：缺乏基于不可变哈希（Manifest Hash Binding）的版本因果图意识。

# 中篇：任务执行端（做题 Agent）易犯的八大系统性错误

当让 AI Agent 作为做题者（Solver）面对数万字真实材料与专业考题时，它表现出的失分模式同样具有鲜明的系统性：

## 1. 表面模式匹配 vs 实质语义盲区：抓得出同义词，辨不清实质变更
- **法律义务倒置的“假同义”放过**：当条款从“验收合格后 30 日内付款”被悄悄改成“货物到货后 30 日内付款”时，由于包含“30日”、“付款”等高重合关键词，做题 Agent 往往自信地判定为“表述一致，无实质差异”，对付款抗辩权的丧失彻底失明。
- **口径差异误判假账**：半年报“重大合同”披露签约额 35,028 万元，“附注”披露实际账面发生额 35,486 万元。由于缺乏会计勾稽常识，Agent 仅因数字字面不相等，就武断得出“前后披露自相矛盾、涉嫌造假”的错误裁决。
- **根因**：过度依赖向量相似度与浅层文本匹配，缺乏穿透商业实质与法律效力的推演支点。

## 2. 跨文档勾稽断链与“局部就近满足”：答出显性要点，丢掉全局暗线
- **贪婪就近满足（Satisficing Behavior）**：从主文档 A 扫出 3 条表面违规点，置信度上升便认为“答题完毕”，立刻停止深入检索。
- **深层暗线系统性遗漏**：真正致命的线索往往埋在附件三附注折旧率变更或附件五督导说明中。实测中受试模型在无显式清单提醒时，系统性漏掉多达 14 项跨附件穷举要件（保证金退还凭证、驻场考核记录等）。
- **根因**：注意力机制向局部最强线索快速收敛，缺乏人类专业人员“翻烂所有附件、穷尽证据链”的系统性审计耐心。

## 3. 时序因果与权威层级倒错：信息拍平大杂烩，不辨生效与准入
- **次级引述反向纠正法定原件**：拿着公司回复函中引用的媒体报道或券商研报估算，反过来去“纠正”经过独立审计的法定财务报表，效力层级彻底颠倒。
- **草案当现行、作废当有效**：把尚未经股东大会批准的重组预案、或已被补充协议废止的旧合同条款，直接作为当前已生效的权利义务基准进行责任推演。
- **代际租约混淆（Xpert 00399）**：分不清“身份合法（AuthN）”与“当前代际租约有效（Incarnation）”，用已过期的合法旧代凭证执行新代数据迁移。
- **根因**：将输入材料拍平成静态事实知识库，缺乏动态跟踪“提议→审议→批准→生效→作废”的事件溯源心智。

## 4. 强行补全与“拒绝无能”：恐惧不确定性，在证据缺失时硬算
- **无中生有的虚假点估计（Point Estimate）**：当关键折现率在材料中未披露时，专业解法是“数据缺失，无法推导，需做敏感性区间或暂缓”。但做题 Agent 极度恐惧空白，会基于预训练常识捏造一个 8.5%，强行代入公式算出一个极其精确但毫无根据的虚假数值。
- **证据类别越界**：在要求严格区分 `reported（原始披露）/ derived（推导）/ conditional（条件）/ unavailable（不可得）` 时，Agent 几乎从不主动选择 `unavailable`，宁可严重幻觉也要强行确认为推导结论。
- **根因**：受自回归生成机制与 RLHF 迎合偏置驱使，将“承认未知”视为任务失败，无法理解风控中“不讲没有证据的话”的价值。

## 5. “重算数而轻定性”的逃避策略：数字精确漂亮，实质定性全靠套话
- **Xpert L04 经典案**：“数字命中很多、定性项没判”。算起 WACC、IRR 和跨期折旧摊销行云流水；但面对“是否构成重大借壳”、“免赔额是否因恶意而归于无效”等定性问题时瞬间哑火。
- **万能公文套话敷衍**：充斥着“存在一定风险”、“需结合实际情况综合判断”、“建议加强内控”等废话，写满几百字却不敢给出二值化的确切定性断言，定性考核点大面积失分。
- **根因**：计算有明确公式属于安全区；定性涉及商业利益与法律冲突，Agent 本能地逃避承担确定性断言的责任。

## 6. 原值与显示值脱节：受制于截断表格，陷入“尾差幻觉”
- **截断显示值放大多步误差**：表格为了排版美观展示保留 2 位的截断值（如 12.35 万元）。Agent 直接拿截断值做多步连续复合运算，乘数效应成倍放大，导致最终结果与金标准产生几分钱或几个百分点的“尾差漂移”，被严格容差直接拦截。
- **台账勾稽被“假平衡”欺骗**：盲目相信报表上打印出来的合计行，无法识别出报表通过人为硬凑尾差实现的假平衡。
- **根因**：缺乏真正的底层数值类型感知（Type Awareness），把展示用的排版文本与计算用的高精度浮点原值混为一谈。

## 7. 思考路径的“倒果为因”：先定预设立场，再倒贴虚假引用
- **跳步与结论先行**：思考过程前两步还在分析公司 A 的免责条款，第三步毫无推导过渡地直接跳出“综上所述，公司 A 构成重大违约应全额赔偿”。
- **引用张冠李戴（Citation Hallucination）**：要求标注文档名、页码与行号时，把附件一第 5 页的数字煞有介事地标注为“附件三第 28 页表 4-2”，而翻查该页根本无此表格；甚至推导过程列了三条反驳理由，最终选项依然勾选成立。
- **根因**：大模型生成受到整体语义场的概率牵引，预设了刻板立场后，注意力机制倒推强行拉扯无关片段做背书。

## 8. 输出规范的角色违和与“工程师傲慢”：动不动吐代码，讲不清人话
- **文职角色输出 JSON 结构体**：要求以资深法务顾问身份为董事会起草法律备忘录，Agent 却在正文大段嵌套 Markdown 代码块、JSON 字典甚至 Python 脚本，被专家批注“文职专家绝不会向管理层提交这种技术半成品”。
- **严格契约下的客套话灾难**：要求严格按 `Q1: 结论; Q2: 金额` 输出时，Agent 忍不住倾倒“您好！我是您的专业助手很荣幸为您解答……”等废话，直接搞垮下游自动化评分管道。
- **根因**：技术文档与代码数据训练过载，缺乏对高级商业社会的专业语境、文体规程与沟通礼仪的真实理解。

# 下篇：究竟怎样出题才能真正难住 Agent？（实战验证的有效杠杆）

既然 Agent 在做题时有上述软肋，而出题时又容易走入“堆算量”或“故意歧义”的死胡同，那么在严苛的工业级评测中，**究竟该如何设计题目，才能在保证题面绝对规范清晰的前提下，真正把最前沿的 AI Agent 牢牢难住（稳定压制在 ≤60% 甚至 ≤50% 达标线以下）？**

在 Xpert 与 TalentsAI 的数十轮淘汰赛中，我们首先付出了沉重的试错代价，明确排除了所有“伪加难手段”，最终筛选出了被实测验证真正具备物理穿透力的有效杠杆。

## 一、已经彻底证伪的“伪加难手段”（必须全面停用）

在尝试降低模型得分的过程中，以下手段已被无数次失败数据证明**完全无效**，严禁在出题中继续使用：

| 伪加难手段 | 实测惨剧样本 | 为什么彻底无效 |
|---|---|---|
| **往题面加条款、加判定表、加要求清单** | 00399 v8 追加混版防线、成本取舍等 4 类要求，模型按清单逐条完成 36 项判定，拿下近满分 | **加条款等于给清单**。现代模型是清单执行大师，提示词写得越细，它越能按部就班逐条打钩。 |
| **加数据量、加行数、加附件厚度** | 3659 题将数据扩充到 6000 行，模型依然全对；4237 加厚材料后前端口径仍对 | **规模不改变判断拓扑**。长上下文窗口（Long Context）让模型做海量检索如探囊取物。 |
| **加算术量、多分桶、加复杂公式** | 4169 题绑定 30 条跨表数值，前沿模型零失误算完；168352 拼命追加商誉与权益桥，模型依然 100% 满分 | **算术不是模型的弱项**。规则明确的计算题，模型甚至比人类更不容易算错。 |
| **粗暴抽掉输入逼模型选“无法判断”** | 00516 故意隐去输入逼模型输出区间与分支，试答依然拿下 70 分；平台质检直接打回 | **平台质检不认缺材料做难度**。这属于题面瑕疵而非专业难度，且模型会靠合理假设绕过。 |
| **寄希望于改严 Rubric 扣分** | 00516 档位分解：A/C/D/H/J/K 六条共 52 分，只要“写清报告结构”就能拿满 | **结构分托底效应**。只要题目属于“方案/规划”，结构分就能托住 60+ 底分，改判断项无法突破 50。 |

## 二、被实战验证真正有效的五大核心杠杆

真正能把前沿模型打下神坛的题目，其本质是**利用模型在“预训练概率场”、“局部就近满足”与“动态状态追踪”上的内在机械缺陷**。以下五大杠杆已在实战中取得稳定验证：

### 杠杆 1：≥3 个近似口径成组并存（打破结构分托底，逼出跨文档准入抉择）
这是唯一在 FDE1564 样题（实测合格）与 178819 终极版中跑通的降维打击手段。

- **实操做法**：
  在材料里对同一个核心商业对象，同时提供 **3 份不同来源、不同口径的数据**（例如：统计局口径的行业社保基数、财政税务申报口径的实缴基数、企业内部财务账套口径的计提数；或者“期末余额 vs 日均余额”、“合同签约日 vs 实际发票日 vs 验收审计日”）。
- **题面契约**：
  题面只给出高阶法定业务目标（如“按监管数据字典规定的法定有效申报规则完成汇算”），**绝不点破哪份数据对，绝不提示存在冲突**，并在规则中严厉禁止混用口径。
- **失分机理**：
  做题 Agent 无法依靠通用报告模板拿到“结构分”。它必须执行完整的证据准入链：从附注小字中找到法律效力认定，剔除另外两个看似更诱人但属于次级的口径，得到唯一法定申报值。如果它按默认习惯混用了不同口径，下游所有依赖该指标的核算与风险结论将全盘连带崩溃。

### 杠杆 2：埋入符合预训练直觉的“顺手但错”认知陷阱（Cognitive Trap）
让做题 Agent 败给自己的“惯性直觉（System 1）”。

- **实战样本（01302 实证）**：
  在架构规划材料中，故意放置一个“没有正式书面 SLA 承诺、但单价极其低廉”的弹性云资源，并与高价正式资源并列。题面在总规则中写明“未经书面保障的资源按不可用处理”。
  - **模型的表现**：受试模型在做方案规划时，出于成本最小化本能，顺手把该便宜弹性资源作为主要算力来源编入方案；同时在文档某处又客观摘录了“该资源未获确认”。整套答卷瞬间构成严重的自相矛盾，直接判负。
- **4464 实证**：
  材料规定“保单免赔额修订仅对新单生效”。题目给出一份出险理赔清单，模型在做案头赔付时，极度顺手地按照“事故发生日”或“报案日”切分适用条款，而忽略了必须深挖保单背后的“原始投保签约日”。这种“顺手但错”的认知直觉，前沿模型百试不爽。

### 杠杆 3：跨层因果级联传播（Cascading Downstream Disruption）
拒绝孤立问答，构建牵一发而动全身的决策状态机。

- **实操做法（领航 110 & 224835/224836 实证）**：
  将一道题目的主线串联为不可逆的四阶段决策链：
  $$\text{证据准入} \longrightarrow \text{计量口径选择} \longrightarrow \text{跨表跨期桥接} \longrightarrow \text{下游经营/风控闭环}$$
- **失分机理**：
  题目各部分绝对不是割裂的子任务。做题 Agent 面对的第一步是一个具有迷惑性的准入裁决（例如某笔海外股权质押是否应当计入归母可分配利润）。如果它在第一步被表面文字欺骗给出了错误定性，这个错误就会像毒素一样沿着整条因果链向下扩散：资产负债表不平、现金流折现崩塌、最终的投资决策建议被彻底引向灾难。在实测中，这种级联题目一旦上游犯错，整体得分往往瞬间跌落至 20%~30%。

### 杠杆 4：行级全量穷尽 + 三类隐蔽物理陷阱（Row-Level Structural Traps）
打破模型抽样检查的侥幸心理，建立数据物理自洽约束。

- **实操做法（4237 实证）**：
  要求对成百上千笔业务明细做全量逐笔清洗与判定，并在数据底层设计三类物理陷阱：
  1. **冲销与负数红冲行**：同一笔交易存在历史冲销，字面完全相同但金额为负；
  2. **跨附件联合主键**：仅凭单表 ID 无法唯一确定记录，必须联合合同补充协议的时间戳；
  3. **伪平衡台账**：明细数据加总与报表打印的合计行存在 0.01 尾差。
- **失分机理**：
  要求模型交付的分桶总数、明细行、汇总金额三者必须具有绝对数学一致性。做题 Agent 的注意力机制在处理巨量明细时，必然发生局部信息遗忘（Attention Drop）。只要遗漏或误判了哪怕一行冲销数据，其汇总合计与明细分桶就会出现断层，机器一键对账当场爆零。

### 杠杆 5：强制二值化裁决与反套话硬门禁（Anti-Platitude Binary Adjudication）
彻底剥夺做题 Agent 躲在“公文废话安全区”里的退路。

- **实操做法**：
  在 Prompt 中明确列出黑名单：**“凡输出‘需结合实际情况’、‘存在一定风险’、‘建议进一步论证’等非确定性表述，一律判定为零分”**。强制要求给出不可撤回的二值化判定：
  - “本次重组是否触犯借壳红线？只能回答【触犯】或【未触犯】；并给出依据哪一条哪一款的法律断言”；
  - “临界值恰好等于触发线（如资本充足率恰好 10.5%），必须明确回答【达标】还是【违规】，并写出不含舍入误差的精确分子分母”。
- **失分机理**：
  做题 Agent 的对齐机制使其天生倾向于模棱两可、中庸骑墙。一旦封死套话退路，逼它在刀刃上跳舞，其在面对边界临界值与法理冲突时的真实推理短板就会暴露无遗，得分断崖式下跌。

# 终局复盘：出题、做题与防线的镜像统一

回顾这上、中、下三篇，我们会清晰地看到一条贯穿整个智能评测工程的主线：

```
出题端常犯的错          做题端常犯的错          真正能难住它的题目
──────────────        ──────────────        ────────────────
迷信堆算量与分桶  <==>  极度擅长机械算量  <==>  换用多口径竞争与准入决策
靠题面故意歧义压分 <==>  依赖表面模式匹配  <==>  埋入顺手但错的认知陷阱
标答抄模型产生近亲 <==>  倒果为因捏造引用  <==>  跨层因果级联与二值化断言
```

在 AI Agent 时代，构建一套高质量的文字与认知评测，其难度绝不亚于设计一枚精密的航空发动机。**我们不能指望一个存在认知缺陷的出题 Agent 能自动造出好题；唯有人类架构师深入理解做题 Agent 的心智边界，用不可妥协的真实业务摩擦与状态机因果去筑起堤坝，才能建立起真正具备技术辨识力的工业级基准。**

> [!SUMMARY] 全文核心避坑与命题法则
> - **出题避坑**：坚决摒弃伪脱敏与堆算量，绝不靠题面歧义压分，标答必须脱离模型独立闭环复算；
> - **做题纠偏**：警惕表面同义词陷阱，防止就近满足遗漏暗线，直面定性裁决，严惩强行硬算与伪造引用；
> - **加难法门**：禁用无效清单与规模堆砌；主打**多口径并存竞争**、**顺手但错的直觉诱饵**、**跨层因果级联**与**强制二值化反套话**。
