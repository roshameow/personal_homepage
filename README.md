## Local preview

Install Ruby and Bundler, then run:

```bash
bundle install
bundle exec jekyll serve
```

The configured site path is `/personal_homepage/`. Posts live under `docs/_posts/`; navigation and site settings are in `_data/` and `_config.yml`.
