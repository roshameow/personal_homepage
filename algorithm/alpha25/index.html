1.2 平台固定公式与经验排序猜想

0. 平台官方刚性结算硬边界（[$1.00, $60.00]）

根据 WorldQuant BRAIN 官方文档与顾问规则，每日 Base Payment 的硬性物理边界严格为 $1.00 到 $60.00（最低底薪保底 $1.00，最高单日封顶 $60.00，总有效跨度为 $59.00）

1. 官方规则框架与横向排位锦标赛机制（官方文档与平台规则）

  • 四大核心维度：官方明确定义顾问 Base Payment 由四大维度共同决定： \[\text{Base Payment} = \Phi\big(\text{Quality Factor}, \text{Quantity Factor}, \text{Self Growth Factor}, \text{Value Factor}\big)\]

  • 全网横向排位锦标赛机制（Tournament / Relative Ranking）： 平台官方反复强调，顾问的每日 Base Payment 并不是单独考核你这一只 Alpha 的绝对表现，而是把全网全体顾问当天提交的全部 Alpha 放入同一个动态池子里进行横向相对排位（Relative Ranking）。每日的总奖金预算在池中依据相对分位数进行分配切分。

2. 用户提供的乘数合并固定公式（官方社区讨论规范）

  • Quality Factor（质量因子）的构成： 在平台官方规则体系中，单 Alpha 的 Quality Factor（即单体质量得分 \(q_i\)）由四大要素共同决定：
    1. Fitness（回测适应度指标，\(f_i\)）；
    2. Production Correlation（生产池低相关性指标，\(p_i\)）；
    3. Region & Universe（资产所属宏观区域与流动性宇宙范围，\(r_i, U_i\)）；
    4. Final Multiplier（最终复合乘数，\(M_{\text{final}, i}\)）。

    其中，前三项共同决定该 Alpha 的固有质量基底（未知函数形式）： \[b_i = g(\text{Fitness}_i, \text{ProdCorr}_i, \text{Scope}_i)\] (注：此时仅知其为这三项指标的函数，具体是独立加法还是连乘漏斗、各门槛权重多少，均未提供，属于后续第三阶段逆向实证求解的核心目标)。 第四项 Final Multiplier 则作为质量放大乘数与该基底直接相乘，共同构成单体 Quality Factor： \[q_i = \text{Quality Factor}_i = b_i \times M_{\text{final}, i} = g(f_i, p_i, r_i, U_i) \times M_{\text{final}, i}\]

  • 乘数合并固定公式： Theme 与 Pyramid 属于同级 multiplier，按“两项相加 − 2 + 1”合并；Osmosis 作为全网组合排位最后连乘。三者已全部内化收敛至最终复合乘数 \(M_{\text{final}, i}\)： \[\text{Merged Multiplier} = P_i + H_i - 1\] \[M_{\text{final}, i} = \text{Merged Multiplier} \times (1 + \text{daily\_osmosis\_rank}) = (P_i + H_i - 1) \cdot (1 + o_{u,d})\] (注：Pyramid Multiplier、Theme Multiplier 与 Osmosis Rank 均不单独进入质量加法，而是统一内化为该单体复合乘数 \(M_{\text{final}, i}\) 参与计算)

3. 用户经验中的 Tie Breakers 门槛与排序猜想

  • Tie Breaker 离散门槛定义（经验关注项）：
    • A: \(fitness > 2.0\)（基础优质线）
    • B: \(fitness > 5.0\)（超常优质线）
    • C: \(\text{Theme} \ge 2.0\times\)（有效主题加成）
    • D: \(\text{Prod Corr} < 0.5\)（低相关及格线）
    • E: \(\text{Prod Corr} < 0.3\)（极低相关稀缺加成）
    • F: \(\text{Prod Corr} > 0.7\)（高相关拥挤/惩罚线）
    • G: \(\text{Value Factor} > 0.9\)（高资金容量基底）
    • H: 数量交满 4 个（\(N \ge 4\) 满配额奖励线）：顾问圈普遍经验认为单日交满 4 个 Regular Alpha 享有额外的底薪配额跃迁加成（Quota Bonus），收益远超单纯按件计费的线性叠加。
  • 经验排序猜想（待检验假设，非确定性法则）：
    • 猜想一：\(AC > BE\)
      (直觉猜想：\(fit>2\) 结合 Theme 2x 能否凭借乘数杠杆超越无 Theme 的极品单 \(fit>5\) 且 \(pc<0.3\)？实证表明模型不能普遍保证此不等式，需视具体综合分与 S 曲线位置而定)
    • 猜想二：\(VF\,0.77 + E > VF\,1.0 + D\)
      (直觉猜想：低 VF 下的极低相关 \(pc<0.3\) 能否胜过满 VF 下的普通及格 \(pc<0.5\)？实测证实 \(pc<0.3\) 确实享有显著阶跃加分，但在具体金额映射下需结合批次共同计算)

4. 逆向闭环的生产固定执行公式 (guarded_v2 SSOT)

基于真实数据验证，确立全链路生产闭环数学规范： \[b_i = 0.48 + T_{pc}(p_i) + T_{fit}(f_i) + D(r_i, U_i)\] \[M_i = P_i + H_i - 1, \qquad q_i = b_i M_i (1 + o_{u,d})\] \[S_{u,d,h} = v_{u,d}^2 \cdot C_h(N) \cdot \frac{1}{N} \sum_{i=1}^N q_i\] \[\widehat{B}_{u,d,h} = 1.00 + 59.00 \cdot \sigma\left(k_h \big[S_{u,d,h} - s_h(d)]\right), \quad \sigma(x) = \frac{1}{1 + e^{-x}}\]

1.1 假设：多因子加权线性模型		 Base Payment 是否是各项回测指标（Fitness, ProdCorr, Multiplier）的加权线性组合？ 实验：使用 OLS 对双账号 764 天真实结算记录进行拟合。
• 现象 A（边界截断崩溃）：模型在弱指标批次频繁产出负值（甚至达 -$15.00），在高分日肆意冲破 $90+，完全脱离平台 [$1.00, $60.00] 的硬边界。
• 现象 B（边际递增不符）：中位收益带（$15 ~ $45）具有极高边际敏感度，线性拟合 \(R^2 < 0.35\)，残差异方差极其显著。		 排除
1.2 假设：锦标赛粗暴阶梯分档制（Tiered Brackets） 背景：平台固定金额猜测

在全网横向排位中，平台是否按固定排位比例分档定额发钱（如 Top 5% 统一发 $50，Top 5%~15% 发 $35，后 60% 发保底）？		 观测：统计历史 700+ 天真实结算单。
• 若为固定比例阶梯分档，实发金额应高度聚集在少数固定的整数或离散档位上；
• 实测到账金额呈现极度平滑、连续分布的小数（如 $51.29, $47.76, $38.25, $17.39, $7.23, $2.77），不存在任何离散台阶断层。		 排除
1.3 假设：动态总预算池比例切分制（Dynamic Budget Sharing） 背景：平台固定金额猜测

平台是否每日设定固定总奖金池上限 \(B_{\text{total}}\)，按当日排名前列者的得分权重直接按比例切分（\(\text{Base}_i = B_{\text{total}} \cdot S_i / \sum S_j\)）？		 观测：对比全球大赛、主题活动期（全网日提交量翻倍暴增）与常规淡季。
• 若纯按固定总预算比例切分，提交量激增时单价必然遭到严重稀释；
• 实测在大赛活动期，高分优质 Alpha 的结算金额并未被大量稀释，与淡季同等质量表现维持高度稳定。		 排除
1.4 假设: 基准分布分位数 S 曲线映射（Benchmark CDF / Logistic Mapping） 背景：数学上算式简单, 符合逻辑

• 假设全网提交符合单峰钟形Logistic 分布，其累积分布积分（CDF）是两端平坦饱和、中段陡峭跃迁的 S 曲线（Sigmoid （1/(1 + e⁻ˣ)）；

• Logistic 分布比正态分布具有更高的峰度和更厚的尾部

平台维护全网大盘单峰钟形基准分布，计算个体综合潜变量得分 \(S_i\) 的累积超越分位数 \(u_i = \sigma(k[S_i - s_0(t)])\)，并线性映射至官方刚性边界 [$1.00, $60.00]：
\[\mathbf{\text{Base}_i = 1.00 + \frac{59.00}{1 + \exp\left(-k [S_i - s_0(t)]\right)}}\] 		理论与实证：
• 全网 70%+ 提交扎堆于及格线附近（单峰钟形密度），其累积分布积分（CDF）在数学上天然涌现为两端平坦饱和、中段陡峭跃迁的 S 曲线（Sigmoid）；
• 对该映射取反函数，严格导出后续所有内层检验的合法因变量变换：
\[y_i = \text{logit}\left(\frac{\text{Base}_i - 1.00}{59.00}\right) = k S_i - k s_0(t)\] 		待定

5.3 大盘时序漂移的“分段跃迁 + 连续偏移”模型推导

在关于时序演化的深度讨论中，用户明确纠正了“机械固定 28 天节点并做连续插值”的人为限制，指出大盘难度演化具有两层异构结构：跨宏观周期的段间水平跃迁（Regime Shift） 与 段内连续渐进漂移（Continuous Drift）。

一、数学模型拆解

设任意结算日 \(t\) 的全网大盘综合难度尺度为 \(\widehat{D}_Q(t)\)，其对数形式可严格正交分解为： \[\log \widehat{D}_Q(t) = \underbrace{\mu_{r(t)}}_{\text{宏观周期分段水平 (Regime)}} + \underbrace{\delta(t)}_{\text{段内平滑连续偏移 (Within-Regime Drift)}}\] 归一化质量分相应表达为： \[s_{Q,u,t} = \frac{Q_{u,t}}{\widehat{D}_Q(t)} = Q_{u,t} \cdot \exp\big(-[\mu_{r(t)} + \delta(t)]\big)\]

二、机制启示

  1. 破除机械周期：分段节点 \(r(t)\) 并非日历月或固定 28 天，而是由平台宏观竞争环境、重大赛事或规则调控事件驱动的离散阶跃；
  2. 段内连续性：在同一制度段 \(r(t)\) 内，随着全网提交池累积，\(\delta(t)\) 呈现微弱平缓上升；
  3. 解释跨周期残差：解释了为何单一固定斜率的时序模型在某些季度会出现系统性偏离，而同日双账号差分却能完美归零。
