2. 核心翻页检测算法技术细节深度拆解 (The Science)

在 LessonCap 的下一步迭代中，我们将从 dHash 升级到 SSIM。以下是各算法的无损技术对比：

2.1 dHash (Difference Hash) - 【LessonCap 目前采用】

  • 原理：将图像缩放至 9x8 灰度图，计算相邻像素的梯度（左像素是否比右像素亮），生成 64 位二进制指纹。
  • 数学本质：基于一阶导数的结构特征提取。
  • 评价：计算开销极低（每秒可处理数百帧），对亮度、对比度变化不敏感。局限性是对于滚动弹幕这种改变了局部像素梯度的干扰，容错率有限。

2.2 pHash (Perceptual Hash)

  • 原理：采用 DCT (离散余弦变换) 将图像转为频率域，保留低频分量。
  • 数学本质：基于频率分布的特征提取。
  • 评价：比 dHash 更稳健，能过滤掉一些高频噪点。但计算成本翻倍，对实时直播监测有微小延迟。

2.3 SSIM (Structural Similarity) - 【LessonCap 升级目标】

  • 原理：通过对比两张图像的亮度 (Luminance)、对比度 (Contrast) 和结构 (Structure) 三个维度。
  • 数学模型：SSIM(x,y) = [l(x,y)^alpha] * [c(x,y)^beta] * [s(x,y)^gamma]。
  • 评价：这是目前最接近人类肉眼判断的指标。它能识别出“文字内容没变，只是上面飘过了一行弹幕”这种场景。它是解决“弹幕干扰”的终极武器。

2.4 HMM (Hidden Markov Model) - 【天花板算法】

  • 原理：将视频建模为一系列隐藏状态（如：幻灯片A、转场中、幻灯片B）。通过 Viterbi 算法 计算观察序列（当前帧）背后最可能的隐藏状态路径。
  • 评价：能自动“抹平”讲师在镜头前走动产生的假翻页。但它需要对每一类视频进行“概率训练”，不符合 LessonCap “即开即用”的工具属性。

3. LessonCap 的竞争壁垒与护城河 (Product Moat)

  1. 场景通杀性 (Unrestricted Sources)：不受软件的“私有协议”限制。用户可以在任何播放器、任何网页、任何会议软件上使用。
  2. 极致轻量化 (Go + Wails)：相比 Python 实现的项目（体积几百MB，需要安装各种环境），LessonCap 编译后仅 15MB 左右，内存占用不到 50MB。
  3. 100% 隐私零风险 (Total Local)：所有识别（包括未来的 OCR）全部调用操作系统本地接口，不与任何互联网服务通信。

4. 未来 12 个月详细开发路线图 (2026 Roadmap)

Phase 2: 智能化飞跃 (智能去重与文字化)

  • SSIM 智能去重内核：引入结构相似性比对，将翻页识别精度提升至 99.9%，并实现弹幕完全过滤。
  • 原生系统 OCR 集成：
    • macOS: 接入 Apple Vision Framework。
    • Windows: 接入 Windows.Media.Ocr。
    • 结果：PDF 课件将带有隐藏的文字层，支持直接 Ctrl+F 搜索。

Phase 3: 生产力生态 (联动与外设)

  • 多显示器支持：自动探测副屏 DPI，解决 4K 扩展屏下的坐标错位。
  • 笔记软件一键导入：支持自动将截图发送至 Obsidian, Logseq 或 Notion。
  • Markdown 联动：自动生成一个包含所有课件截图、时间戳和备注的 .md 索引文件。

报告生成日期：2026年6月14日 结论：LessonCap 的核心使命是成为“每个学生桌面上的必备笔记伴侣”。
