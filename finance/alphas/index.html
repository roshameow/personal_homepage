二、BRAIN 仿真参数与数据形态

2.1 核心仿真参数

仿真参数决定因子回测的信号输入范围与仓位后处理边界，分为数据库与时点选择和持仓权重后处理两类：

参数类别 参数名 核心含义与工程设置建议
数据与时点 Delay 信号滞后天数：Delay-0 为当日收盘前依据当日数据调仓；Delay-1 为次日开盘/日间依据前一交易日收后数据调仓（门槛要求差异明显）
  Test Period 从历史样本中保留一段作为样本内测试区间（对应 PnL 曲线中橙色区间，用于检验参数过拟合）
  Universe 选股股票池（例如 TOP3000 指按日均成交额/成交量排序流动性最高的 3000 只股票）
权重后处理 Neutralize 均值归零中性化：截面按 group_neutralize 消除市场/行业/板块暴露（避免不同类型股票不公平对比）；时序可通过多空结构或 ts_* 消除长期漂移
  Decay 在最终 L1 归一化权重之后 施加的线性衰减平滑（把过去 n 天目标权重按线性递减权重混合），用于压降换手率
  Truncation 单只股票最大权重上限：建议设置在 0.05 ~ 0.1（5% ~ 10%）之间，防止少数异常标的主导组合风险
  Pasteurization 池外过滤：只保留处于当前 Universe 之内的股票数值，对池外股票赋 NaN，避免非流动性小盘股干扰均值与归一化
  NaN Handling 缺失值处理：OFF 模式下当某只股票出现 NaN 时会强制平仓卖出
  Unit Handling 单位一致性校验开关：若表达式出现跨量纲直接相加减（如价格加市值），触发单位不匹配告警

2.2 三大原生数据结构

  • Matrix（时间 × 股票二维矩阵）：每个交易日、每只股票严格对应单一标量值，绝大多数标准算子与回测输出均以 Matrix 形态流入交易引擎。
  • Vector（不等长事件/明细矢量）：同一交易日内单只股票可能对应 0 ~ N 条明细记录（如盘中分钟切片、新闻条数、债券存续列表、分析师明细）；必须先经 vec_avg / vec_sum / vec_max / vec_count 等矢量算子归约为 Matrix 才可参与下游运算。
  • Group（离散分组编号）：每只股票所属的类别标签（如 country、sector、industry、subindustry，或由 bucket 动态生成的分箱标签），专供 group_* 系列算子在组内求均值、排名或中性化。

三、仿真交易执行流程（从 Matrix 到 PnL）

BRAIN 的日频调仓与收益核算遵循严谨的资金中性规则（参考 How BRAIN Platform Works）：

  1. 恒定账面资金规模（Book Size）：每日以固定名义总头寸 $20M（Book Size = $20 million） 进行多空双边交易（由 $10M 多头与 $10M 空头合计构成 $20M 总敞口）。
  2. 中性化与 L1 权重归一化：
    • 将表达式逐日计算在所有候选股票上得到原始 Alpha 评分矩阵 \(\alpha_{t,i}\)；
    • 按设置的 Neutralize 分组在组内去均值，并执行 L1 归一化 使当日截面所有股票权重绝对值之和等于 1（若按多分组独立中性化并各自缩放到对应资金比例，则每组拥有独立子组合资金上限，总和仍守恒为全市场 Book Size）： \[w_{t,i} = \frac{\tilde{\alpha}_{t,i}}{\sum_j \lvert \tilde{\alpha}_{t,j} \rvert}\]
  3. 每日资金分配与损益核算：
    • 当日向股票 \(i\) 分配的名义头寸为 \(w_{t,i} \times \text{Book Size}\)；
    • 若后续施加 Decay 与 Truncation，权重经线性历史平滑与单票截断并再次满足资金约束后，乘以下期标的日收益率得出组合每日 PnL。

四、评测术语与 Alpha 通关/提交指标体系

4.1 基础金融术语

  • PnL（Profit & Loss）：每日组合盈亏 \(\text{daily PnL}_t = \sum_i \text{Position}_{t,i} \times r_{t+1,i}\)，其中单股日收益 \(r = \frac{\text{close}_t}{\text{close}_{t-1}} - 1\)。
  • Returns（年化收益率）：\(\text{Returns} = \frac{\text{Annualized PnL}}{\frac{1}{2}\text{Book Size}}\)（BRAIN 以单边资金 $10M，即 Half of Book Size 为分母计算回报率）。
  • Drawdown（最大回撤）：PnL 曲线从历史高点到低谷的最大回落幅度，同样以 Half of Book Size 归一化为百分比。
  • Margin（交易边际收益，bps）：\(\text{Margin} = \frac{\text{PnL}}{\text{Total Dollars Traded}}\)，衡量每一美元换手金额创造的收益空间，直接决定策略抵御冲击成本与手续费的能力。
  • Long / Short Count：多头与空头持仓股票家数；与 Volume（成交量）、Cap（总市值）共同检验信号广度与容量。

4.2 核心提交指标要求与优化抓手

评估维度 (官方文档) 通关 / 建议门槛 核心计算与判定逻辑 常见瓶颈与优化抓手
Sharpe（年化夏普率） Delay-0: Sharpe > 2.0
Delay-1: Sharpe > 1.58		 \(\text{Sharpe} = \frac{\text{mean}(\text{PnL})}{\text{stdev}(\text{PnL})} \times \sqrt{252}\) 提升多空截面单调性、消除未对冲的行业/宏观风格波动
Sub-universe Sharpe sub_sharpe >= 0.75 * sqrt(N_sub / N_univ) * alpha_sharpe
（通常建议 > 0.7 * Sharpe）		 仅保留流动性更核心的子集股票（其余赋 NaN），自动加市场中性化后重测夏普 排查 Alpha 是否过度依赖小盘股/极低流动性股；避免变相写出 1 - rank(cap) 或 rank(-assets)
IS Ladder Sharpe 各阶梯窗口需高于 FAIL_THRESHOLD；若直接超越 PASS_THRESHOLD 可加速通关 按近 2 年、3 年……直至 10 年逐步拉长样本内周期检验稳健性（长窗口通常自然回落） 重点控制中期大回撤（Drawdown）与特定年份失效（如风格切换期崩盘）
Turnover（换手率） 硬性区间 1% < Turnover < 70%
实战建议 < 25%		 日均双边成交金额占 Book Size 比例的均值 ① 增加衰减 Decay / ts_mean / ts_decay_linear；
② 用 trade_when 设置条件触发锁仓；
③ 用 hump / ts_target_tvr_delta_limit 限制权重变化步长
Fitness（综合健康度） Delay-0: Fitness > 1.3
Delay-1: Fitness > 1.0		 \(\text{Fitness} = \text{Sharpe} \times \sqrt{\frac{\lvert \text{Returns} \rvert}{\max(\text{Turnover}, 0.125)}}\) 0.125（即 12.5%）为换手惩罚下限：同时提高 Sharpe / Returns 并压低换手率是提升 Fitness 的主路径
Margin（千分之基点） 常见建议 > 4 bps：
USA >= 5、EUR >= 10、ASI >= 15 bps		 \(\text{avg}\left(\frac{\text{PnL}}{\text{Total Traded Dollars}}\right)\) 在保证净收益前提下显著降低日均无效换手
Weight Test（权重与覆盖率） 单股最大权重 max(weight) < 10%；
长期非零持仓股票数充足		 检查组合集中度与长期有效覆盖度，防黑天鹅单票暴雷与信号断流 ① Truncation 限制在 0.05 ~ 0.1；
② 外层包 rank / quantile 均匀化权重；
③ 用 ts_backfill 补全低频空窗，并用 group_count 排查当日有效覆盖率
Self Correlation（自相关性） 与已提交库内 Alpha 的 PnL 相关性 < 0.7；或相对高相关老 Alpha 提升至 > 110% 夏普 防止在同一逻辑/数据集上重复提交同质化因子 从数据源类别、关系键类型与中性化维度三层拉开差异化
Out-of-Sample（OS 样本外） 提交后持续接受未来真实市场检验 实时追踪样本外 PnL、回撤与相关性衰减 拒绝无经济学依据的多层嵌套参数过拟合
